## Security boundaries

| Boundary | Implementation |
| :-- | :-- |
| **Network isolation** | All components in private subnets; ingest via private link only |
| **Encryption in transit** | TLS 1.2+ on all connections |
| **Encryption at rest** | Cloud-native encryption (KMS-managed keys) on all storage |
| **Access control** | Hilt engineer access via your approval workflow only |
| **No data egress** | Telemetry never leaves your cloud account (except opt-in anonymized exports) |
