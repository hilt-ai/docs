---
title: "Lineage"
description: "Process and data-flow lineage for Linux estates, and exec-based process lineage for macOS."
---

Lineage answers *who launched what* and how data moved between processes. Use the **Linux | macOS** scope toggle — the two estates share the hub but render different graphs.

---

## Linux scope

When a host is selected you can switch between views:

| View | Purpose |
| --- | --- |
| **Data Flow** | Process and data topology for the host |
| **Sessions** | Session-oriented graphs |

Without a host focused, you see a fleet overview of relationships. Drill into a node to continue in [Investigate](/data/investigate).

---

## macOS scope

The graph is built from Endpoint Security `exec` / fork telemetry — every process spawn the kernel sees, with code-signing trust on edges where available. Focus a Mac from the collector sidebar or host picker to narrow the graph.

---
