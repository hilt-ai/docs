title: "Files"
description: "File telemetry and path explorer for Linux and macOS, including removable media on Mac."
---

Files is the fleet file explorer. Use the **Linux | macOS** scope toggle to browse opens, writes, renames, and deletes across your estate.

---

## Linux scope

Browse hosts that report file activity. Drill from fleet overview into a host path browser and per-file detail, then into [Investigate](/data/investigate) for the responsible process.

---

## macOS scope

Telemetry comes from Endpoint Security with code-signing provenance: where a file came from, who wrote it, and whether quarantine flags were stripped.

### Removable media

The Files hub includes **removable media** context — USB volumes, mounts, and AirDrop-related activity. Writes under `/Volumes` are attributed to the application that performed them.

---
