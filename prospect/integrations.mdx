Hilt integrates with the tools your security team already runs.

| Integration | Purpose |
| --- | --- |
| **REST API** | Pull findings, events, hosts, and rules; push review decisions |
| **Webhooks** | Push delivery when findings fire |
| **Slack** | Route notifications into channels |
| **Google Workspace** | Sync your directory to measure collector install coverage against your employee roster |
| **MCP** | Expose permission-scoped tools to AI assistants (early access) |
| **Query** | Natural-language investigation in the console |

Full customer reference: [REST API](https://docs.hilt.ai/api/overview), [Webhooks](https://docs.hilt.ai/administration/webhooks), [Slack](https://docs.hilt.ai/administration/slack-notifications), [Google Workspace](https://docs.hilt.ai/administration/google-workspace), and [MCP](https://docs.hilt.ai/dashboard/mcp-server).
