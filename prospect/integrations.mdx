Hilt integrates with the tools your security team already runs.

| Integration | Purpose |
| --- | --- |
| **REST API** | Pull findings, events, hosts, and rules; push review decisions |
| **Webhooks** | Push delivery when findings fire |
| **Slack** | Route notifications into channels |
| **MCP** | Expose permission-scoped tools to AI assistants |
| **Query** | Natural-language investigation in the console |

Full customer reference: [docs.hilt.ai API](https://docs.hilt.ai/api/overview).
