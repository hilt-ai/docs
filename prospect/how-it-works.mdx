## Deploy in Your Cloud

Hilt runs as a single-tenant deployment in your cloud account—AWS, GCP, Azure, or Ali Cloud. You retain ownership of the infrastructure, data, and access controls. Hilt provisions the analytics stack, dashboard, and private ingest endpoint in your environment.

## Lightweight Collectors

Collectors run on your Linux hosts, macOS endpoints, and containerized workloads. The Linux agent is a static eBPF-based binary with no kernel modules. The macOS agent uses Endpoint Security and optional browser telemetry. On AWS ECS Fargate, where kernel-level access isn't available, a lightweight sidecar delivers the same behavioral coverage without requiring any changes to your application image. Every collector streams metadata to your private ingest endpoint—no file content leaves your environment.

## Behavioral Detection

Hilt builds behavioral baselines for users, hosts, and data flows. After a short cold-start period, ML models score activity against those baselines and surface anomalies for review. Detection focuses on unusual access patterns, not static signatures alone.

## Investigation & Response

The platform dashboard unifies cloud and endpoint telemetry. Security teams can investigate anomalies, trace data lineage, query historical activity, and take response actions such as quarantine. Admin tooling covers users, teams, audit logs, and operational workflows.
