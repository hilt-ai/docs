The Hilt console is the control plane for Data Movement Governance. Navigation matches how operators work day to day.

---

## Sidebar

| Surface | Role |
| --- | --- |
| **Overview** | Editable home widgets for fleet health and recent findings |
| **Collectors** | Linux and macOS agent fleet |
| **Data group** | Investigate, Lineage, Networks, Files, Users, Activity, Credentials |
| **Security group** | Anomalies, Alerts, Exposure, Malware, Frameworks, Quarantine |
| **Settings** | Account, Uptime, System, Teams, Integrations, Admin |

Several Data hubs use a **Linux | macOS** scope toggle so cloud workloads and endpoints share one navigation model.

---

## Top bar

| Control | Role |
| --- | --- |
| **Ask / Query** | Natural-language questions over telemetry and docs |
| **Reports** | Executive and process-intel PDFs |
