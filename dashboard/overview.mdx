Overview page is customizable through a grid of widgets that can be added, placed and removed to summarize fleet health, security posture, and recent activity.

Most widgets are clickable. Click a widget (outside edit mode) to jump to the page where you can investigate that signal in detail.

## How the page is organized

### Default layout

New users start with six widgets:

| Row | Widgets |
| --- | --- |
| 1 | Events analyzed · Monitored hosts · Users tracked |
| 2 | Security impact (full width) |
| 3 | Threat profile · Recent findings |

You can add more widgets, remove defaults, and rearrange the grid. Your layout is saved per user.

### Edit mode

Click **Edit dashboard** to customize the page:

- **Drag** a widget to move it.
- **Resize** a widget from its bottom-right corner.
- **Remove** a widget with the × on its tile.
- **Add widget** opens a panel grouped by category (Key metrics, Fleet & hosts, Network, Files, Security).

Click **Save** to persist your layout, or **Cancel** to discard changes.

## Widget reference

### Events analyzed

**Shows:** Total telemetry events ingested from your fleet in the last 24 hours.

**How to read it:** This is mostly a throughput indicator, large spike may reflect a noisy deployment, batch job, or activity worth reviewing.

**Navigates to:** Investigate (event timeline).

---

### Monitored hosts

**Shows:** Total host count, with alive / stale / dead sub-counts beneath the number.

**How to read it:**

| Sub-count | Meaning |
| --- | --- |
| **Alive** | Collector shipped events recently |
| **Stale** | Missed recent heartbeats but still within grace period |
| **Dead** | No events for an extended period |

**Navigates to:** Collectors.

---

### Users tracked

**Shows:** Distinct user identities observed across the fleet in the last 24 hours.

**How to read it:** Tracks who is active on your infrastructure.

**Navigates to:** User Timeline.

---

### Security impact

**Shows:** A full-width panel with impact metrics and a trend chart over a selectable time window (24h, 7d, 30d).

**How to read it:** Shows anomaly volume, triage load, and model accuracy signals over time.

**Navigates to:** Anomalies.

---

### Threat profile

**Shows:** A radar chart of anomaly types from the last 24 hours.

**Axes (finding categories):**

| Category | What it represents |
| --- | --- |
| Activity spike | Unusual process or execution patterns |
| Network | Suspicious or anomalous network behavior |
| Sensitive file | Access to sensitive file paths |
| Lateral movement | Cross-host or phase-related movement |
| Detection rule | Matches from custom detection rules |
| Combined signal | Findings spanning multiple categories |

**Navigates to:** Click a category sector to open Anomalies filtered to that type.

---

### Recent findings

**Shows:** The three most recent anomaly findings, each with severity, type, affected host, and timestamp.

**How to read it:** Easy access triage inbox.

**Navigates to:** Individual finding detail, or Anomalies via **View all**.

---

### Host status

**Shows:** A donut chart of fleet connectivity: alive, stale, and dead hosts as colored segments, with total count in the center.

**How to read it:** A visual ratio of overall fleet health.

**Navigates to:** Collectors.

_Not in the default layout — add via **Add widget**._

---

### Top talkers

**Shows:** The five busiest hosts by network flow volume in the last 24 hours, plus a fleet-wide count of new destinations.

**How to read it:** Highlights hosts generating the most network activity. Expected for data pipelines and backups; unexpected spikes may warrant review on the Networks page.

**Navigates to:** Networks.

_Not in the default layout — add via **Add widget**._

---

### File mutations

**Shows:** Fleet-wide file activity in the last 24 hours, opens, deletes, and unique paths, plus the most active hosts by mutation count (renames, chmods, unlinks).

**How to read it:** Surfaces bulk file changes across the fleet. Spikes can indicate deployments, configuration updates, or destructive activity.

**Navigates to:** Files.

_Not in the default layout — add via **Add widget**._

---

### Open anomalies

**Shows:** Total anomaly count in the last 24 hours with a severity breakdown bar (critical, high, medium, low).

**How to read it:** Triage backlog indicator.

**Navigates to:** Anomalies.

_Not in the default layout — add via **Add widget**._

---

### Detection rules

**Shows:** Count of enabled detection rules out of total configured, plus a scrollable list of rule names with enabled/disabled status.

**How to read it:** Shows rule coverage deployment and activity.

**Navigates to:** Detection Rules.

_Not in the default layout — add via **Add widget**._
