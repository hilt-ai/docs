The dashboard mirrors the sidebar in the Hilt web app. Pages are grouped into **Overview**, **Collectors**, **Cloud**, **Endpoint**, **Security**, and **Admin**, with a standalone **Settings** page.

## Overview

- [Overview](/dashboard/overview): landing page with health signals, recent anomalies, and threat profile

## Collectors

- [Collectors](/dashboard/collectors): fleet list of deployed Hilt collectors and per-host detail

## Cloud

- [Data Lineage](/dashboard/data-lineage): process and data-flow visualization across hosts
- [Networks](/dashboard/networks): TCP connections, destinations, and data transfer
- [Files](/dashboard/files): file opens, writes, renames, and deletions
- [User Timeline](/dashboard/users): user identity and activity across the fleet

## Endpoint

- [EDR](/dashboard/edr): macOS endpoint detection — persistence, tamper detection, data movement, credential & privacy access

## Security

- [Detection & Accuracy](/dashboard/detection-accuracy): how Hilt detects anomalies and measures model accuracy
- [Anomalies](/dashboard/anomalies): ML and rule-based findings for triage
- [Rules](/dashboard/detection-rules): custom detection rule builder
- [Anomaly Windows](/administration/behavioral-suppression): scheduled suppression of ML anomalies during known-noisy periods
- [Fleet behavior](/dashboard/fleet-behavior): behavioral clustering and host movement
- [Investigate](/dashboard/investigate): deep-dive event timeline and filters
- [Query](/dashboard/query): natural-language and structured telemetry queries
- [Quarantine](/dashboard/quarantine): host isolation and blast-radius assessment
- [Reports](/administration/reports): security report generation and PDF export

## Settings

- [Settings](/dashboard/settings): password, username, and session management

## Admin

- [Administration](/administration/layout): users, teams, identity mapping, and platform configuration
- [Model Lifecycle](/on-prem/model-lifecycle): TRACE detection model status, promotion, and rollback
- [Data Export](/on-prem/data-export-overview): anonymized data export review and approval
- [Auto-Update](/on-prem/auto-update-overview): automatic platform update configuration
- [Storage](/administration/storage): telemetry storage usage, tiering, and lifecycle policies
- [Audit Log](/administration/audit-log): authentication and administrative action history
- [MCP Server](/dashboard/mcp-server): Model Context Protocol server for AI assistant integration
