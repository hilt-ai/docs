The EDR pages provide real-time visibility into security-relevant activity on macOS endpoints running the Hilt collector. Each tab focuses on a different category of endpoint behavior, but they share the same layout and controls.

---

## Shared layout

Every EDR tab has the same structure:

- **Agent header**: a bar showing the current host ID, its risk level, last-seen time, Endpoint Security and Network Extension status, policy version, and finding/event counts.
- **Summary cards**: one card per activity group showing the count and top severity for that group.
- **Timeline**: a 60-minute area chart of findings per minute — spikes highlight bursts of activity.
- **Severity / Status filters**: filter findings by severity (critical, high, medium, low, info) and agent response (blocked, alerted, allowed, logged).
- **Findings table**: a grouped, collapsible table of findings with columns for Time, Type / Target, App, Severity, and Status. Duplicate findings are collapsed into expandable groups with a count badge.
- **Finding detail panel**: selecting a finding shows a six-part breakdown: What happened, Process responsible, What was touched, Why it matters, Evidence, and Recommended action.

### Severity levels

| Level | Meaning |
| --- | --- |
| **Critical** | Likely harmful — investigate first |
| **High** | Suspicious and worth prompt attention |
| **Medium** | Noteworthy but less urgent |
| **Low** | Minor or informational |
| **Info** | Routine activity, recorded for the record |

### Agent response statuses

| Status | Meaning |
| --- | --- |
| **Blocked** | The action was actively stopped on the device |
| **Alerted** | Flagged for review |
| **Allowed** | The action was permitted to proceed |
| **Logged** | Recorded for the record |

## Persistence

**Route:** `/edr/persistence`

Monitors programs set to start automatically and survive reboots — launch agents, launch daemons, login items, cron jobs, and Background Task Management (BTM) registrations.

### Activity groups

| Group | What it detects |
| --- | --- |
| **Persistence items** | New or modified launch agents/daemons, scheduled jobs, and login items |

Legitimate applications use persistence mechanisms routinely (e.g., updaters, background services). Findings here are noteworthy when an unknown or unsigned binary registers for auto-start.

---

## Tamper Detection

**Route:** `/edr/tamper`

Detects attempts to weaken macOS security controls or interfere with the Hilt agent itself.

### Activity groups

| Group | What it detects |
| --- | --- |
| **Gatekeeper** | Attempts to disable or bypass macOS Gatekeeper (the protection that blocks untrusted apps) |
| **MDM / Profiles** | Changes to device-management configuration profiles that can alter security settings |
| **Agent tamper** | Attempts to stop, delete, or disable the Hilt collector — which the agent actively blocks |

---

## Data Movement & External Transfer

**Route:** `/edr/data-movement`

Tracks where data leaves the endpoint — external uploads, removable-media writes, and AirDrop transfers. This tab requires selecting a specific endpoint before showing data.

### Activity groups

| Group | What it detects |
| --- | --- |
| **External uploads** | Files read and then sent to an outside destination |
| **Removable media** | Files written to USB drives or other external volumes |
| **AirDrop** | Files transferred via AirDrop |

### Connection graph

A flow visualization at the top of the page shows the endpoint's active network connections — source processes, destinations, and transfer volumes.

### Finding detail — Flow diagram

Data Movement findings include a **Flow** section showing the path data took: the source file, the application that handled it, and the destination address or device.

---

## Credential & Privacy

**Route:** `/edr/credential`

Monitors access to credential stores and privacy-sensitive resources. This tab also requires selecting a specific endpoint.

### Activity groups

| Group | What it detects |
| --- | --- |
| **Keychain** | Access to the macOS Keychain (passwords, keys, certificates) |
| **Browser credentials** | Access to browser saved passwords and cookies |
| **TCC privacy database** | Access to the database controlling app privacy permissions (camera, mic, files, screen) |
| **Camera / microphone** | When the camera or microphone was activated, and by which application |

---

## Selecting an endpoint

The Data Movement and Credentials tabs require you to pick an endpoint before any data is shown. The endpoint picker lists all devices reporting EDR telemetry, with their hostname, host ID, total event count, and last-seen time. Your selection is remembered across page visits.

You can switch endpoints at any time using the **Change** button in the endpoint bar below the page header.
