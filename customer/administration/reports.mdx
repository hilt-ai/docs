Reports opens from the **top-bar** chart control (not the sidebar). It generates infrastructure and security reports from telemetry and findings, exportable to PDF. Two report types are available: an **Executive Summary** and a deeper **Process Intel** breakdown.

## Period selector

A period selector at the top of the page lets you choose the reporting window: **24h**, **7d**, **30d**, **90d**, or **1y**.

---

## Executive Summary report

A one-page executive summary covering the selected period:

- **Risk identified**: a donut of detections by category, with the total anomaly count in the center.
- **Detection funnel**: the stages from _anomalies flagged_ through _analyst reviewed_, _validated threats_, _hosts quarantined_, _hosts sanitized_, and _hosts restored_, with accuracy KPIs including **Detection accuracy** and **False positive rate**.
- **ROI cards**:
  - **Data Collectors Ensuring Complete System Coverage** — with Active, Offline, and Users sub-tiles.
  - **Anomalous out requests intercepted** — with egress and file outbound sub-tiles.
  - **Sensitive file opens blocked** — with deletions and permission changes sub-tiles.
- **Charts**: transfer volume (bytes over time) and file activity over the period.

If there were no detections in the period, the risk donut notes that.

---

## Process Intel report

A per-host process intelligence breakdown for the period, starting with a KPI strip (hosts, distinct programs, total processes, spawn chains, network processes, files touched). It then details:

1. **Top spawn chains**: parent → child process launches, as a chart and table.
2. **Process network activity**: flows, bytes sent/received, destinations, and hosts per process.
3. **Process file activity**: top directories by event volume.
4. **File classification breakdown**: files grouped by class.
5. **Flagged files**: notable files with their class, event count, process, and reason.

---

## Exporting to PDF

**Export PDF** renders the current view and period server-side and opens a full-screen **PDF preview** with a **Download** button. The file is named for the report type, period, and date (for example, `Hilt-Overview-Past-7-Days-2026-06-05.pdf`).

The export produces a PDF only, there's no CSV, email, or share-link option from this page.
