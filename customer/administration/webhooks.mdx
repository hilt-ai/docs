Webhooks live under **Settings → Integrations** alongside Slack and Google Workspace.

Use webhooks to push finding and alert events to your own receivers. For request shapes, authentication headers, and examples, see the [Webhooks API](/api/webhooks).

---

## In the console

1. Open [Settings](/dashboard/settings) → **Integrations** → **Webhooks**
2. Add an endpoint URL and select the event types to deliver
3. Verify delivery using your receiver logs or the API worked example
