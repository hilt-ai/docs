---
title: "Configuration reference"
description: "CLI flags, environment variables, and config file keys for the DMG Collector."
---

The agent accepts configuration via (in order of precedence) CLI flags, environment variables, and `/etc/dag-agent/config.yaml`.

| CLI | Env var | Config key | Default | Purpose |
| :-- | :-- | :-- | :-- | :-- |
| `-s` | `DAG_SHIP_URL` | `ship_url` | unset = file mode | HTTPS collector URL. |
| `-o` | `DAG_OUTPUT_PATH` | `output_path` | `/var/log/dag-agent/events.jsonl` | JSONL output. Set to `-` for stdout explicitly. |
| `-n` | `DAG_NODE_ID` | `node_id` | `$(hostname)` / `spec.nodeName` on K8s | String host label displayed on the dashboard. |
| `-b` | n/a | n/a | off | Benchmark mode; ship only. |
| `-v` | n/a | n/a | off | Verbose: mirror events to stderr. |
| `-V` | n/a | n/a | n/a | Print version and exit. |
| n/a | n/a | `cpu_limit` | no limit | Written as `CPUQuota=` in the systemd drop-in. |
| n/a | n/a | `ram_limit` | no limit | Written as `MemoryMax=` in the systemd drop-in. |
| n/a | n/a | `ringbuf_size` | `1M` | Per-CPU BPF ring buffer size. Increase on busy hosts (`8M`, `16M`). |
| n/a | n/a | `tag_refresh_interval_s` | `1800` (30 min) | How often to re-poll cloud instance-metadata tags without a restart. `0` disables periodic polling. `systemctl reload` always triggers one immediate refresh regardless. Skipped under Kubernetes (node labels used instead). |
