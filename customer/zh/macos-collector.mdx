macOS 采集器将 Hilt 的数据检测与响应覆盖范围扩展到 macOS 端点，补充了覆盖服务器基础设施的 Linux 采集器。两者共同提供跨完整环境的可见性，从云服务器到员工工作站。

---

## 覆盖范围

| 覆盖面 | 技术 | 观测内容 |
| :-- | :-- | :-- |
| **系统活动** | Apple Endpoint Security 框架 | 进程执行、文件操作、网络连接，与 Linux 采集器相同的事件类别 |
| **浏览器活动** | 托管 Chrome 扩展 | 与数据流转治理相关的网页导航模式和下载活动 |

---

## 架构

macOS 采集器由两个组件组成：

### 系统扩展

使用 Apple Endpoint Security (ES) 框架的 macOS 系统扩展。它观测：

- 进程创建和终止
- 文件打开、写入、重命名和删除
- 网络连接建立和数据传输

系统扩展作为具有 ES 权限的用户空间守护进程运行，无需内核扩展 (kext)。

### Chrome 扩展（托管）

通过 MDM 部署的托管 Chrome 扩展，观测：

- 到外部服务的导航
- 文件下载事件
- 上传到云存储和文件共享服务的活动

扩展以只读模式运行，不会修改、阻止或注入浏览器活动。

---

## 部署

macOS 采集器通过你的 MDM（移动设备管理）解决方案部署：

1. **系统扩展**：作为签名的 `.pkg` 安装程序分发，通过 MDM 配置文件批准 Endpoint Security 权限
2. **Chrome 扩展**：通过 MDM 的 Chrome 企业策略强制安装
3. **配置**：摄取端点和节点身份通过 MDM 首选项或配置描述文件配置

### 要求

| 要求 | 详情 |
| :-- | :-- |
| **macOS 版本** | 13.0 (Ventura) 或更高版本 |
| **MDM** | 系统扩展批准和 Chrome 扩展部署所必需 |
| **网络** | 到你的 Hilt 摄取端点的出站 HTTPS |
| **Chrome** | 浏览器可见性需要托管 Chrome（可选组件） |

---

## macOS 采集器不做的事

与 Linux 采集器的设计理念一致：

- **不读取文件内容**：仅元数据（路径、操作类型、大小）
- **不捕获键盘输入或屏幕内容**
- **不阻止或修改活动**：严格只做观测
- **不需要完全磁盘访问权限**：在 Endpoint Security 框架权限内运行
- **不捕获数据包载荷**：仅连接元数据和字节计数

---

## 数据流

来自 macOS 端点的遥测数据与 Linux 采集器数据流经相同的管道：

1. 系统扩展 / Chrome 扩展观测到事件
2. 本地缓冲和噪声过滤
3. 通过 HTTPS 发送到你的 Hilt 摄取端点
4. 在相同的仪表盘视图中可用（调查、网络、文件、用户、异常）

macOS 主机与 Linux 主机一起出现在[采集器](/zh/dashboard/collectors)主机群视图中，带有 **macOS** 主机类型徽章。

## 当前限制（早期访问）

| 限制 | 状态 |
| :-- | :-- |
| 自动更新 | 尚不可用，通过 MDM 包推送升级 |
| 隔离响应 | macOS 尚不支持（AWS 安全组隔离仅限 Linux/云） |
| 行为基线建立 | 支持，但模型预热在高度变化的工作站模式上可能需要更长时间 |
| 自管理部署 | 早期访问期间仅限 MDM |
