创建并管理可登录仪表盘的账户，为每个用户设置角色，并通过团队来限定他们可见的范围。本页面需要 **manage users** 权限。

---

## 概要统计

页面顶部显示总览数字：

- **Total accounts** — 系统中的用户账户总数。
- **Admin count** — 持有 Admin（或 Owner）角色的账户数量。
- **Temporary-password count** — 仍在使用创建时设置的临时密码的账户（即用户尚未在「设置」中更改密码）。

## 过滤栏

用户列表顶部的过滤栏可让你快速缩小结果范围：

- **Search** — 输入用户名、角色或团队名称来过滤列表。
- **Role filter** — 一个下拉框，仅显示特定角色（Admin、Analyst、Responder、Viewer）的用户。
- **Team filter** — 一个下拉框，仅显示特定团队的成员。
- **Result count** — 一个指示器，显示当前过滤条件匹配到多少用户。

---

## 角色与权限

每个用户拥有一个角色。角色选择器中包含一个信息提示，对每种角色进行了说明：

| 角色 | 可执行的操作 |
| --- | --- |
| **Admin** | 完整访问权限，包括管理用户、团队和审计日志。 |
| **Analyst** | 完整的数据访问权限和检测规则管理权限，但无法访问管理类页面。 |
| **Responder** | 与 analyst 类似，但不能创建、编辑或删除检测规则。 |
| **Viewer** | 只读访问权限，外加 AI 查询页面。 |
| **Owner** | 与 admin 相同；固定绑定到初始账户，无法分配给他人。 |

**owner** 角色较为特殊：它锁定在初始账户上，无法分配给其他任何人，也无法被更改、禁用或删除。

### 全局管理员与受限管理员

**全局管理员**（即未隶属任何团队的 admin 或 owner）可以查看所有内容。**受限管理员**则是被分配到一个或多个团队的 admin，他们只能管理自己的子树，并且在创建或编辑用户时，必须至少分配一个其管辖范围内的团队。

## 创建用户

这里没有邮件邀请流程。你需要直接创建账户。点击 **New user** 会打开一个抽屉面板，其中包含：

- **用户名（Username）**。
- **临时密码（Temporary password）**（至少 8 个字符）。在正式部署环境中，这是一个临时密码，用户登录后应在「设置」中将其替换。
- **角色（Role）**（默认为 viewer）。
- **团队（Teams）**：用户所属的团队，决定了他们可见的主机。受限管理员必须至少选择一个团队。

提交后会立即创建账户。密码就是你所输入的内容（它不会通过邮件发送，也不会再次显示），因此请以安全的方式将其告知用户。在正式部署环境中，该账户会被标记为使用 **临时密码**，直到用户设置自己的密码为止。

---

⋯ 操作菜单提供以下选项（是否可用取决于目标对象是你本人、owner 还是其他用户）：

| 操作 | 说明 |
| --- | --- |
| **Rename user** | 修改用户名 |
| **Edit role & team** | 修改角色和团队成员归属（对 owner 不可用） |
| **Reset password** | 设置一个新的临时密码 |
| **Disable / Enable account** | 阻止或恢复登录（对 owner 不可用） |
| **Delete user** | 永久移除账户（对 owner 不可用） |

<Note>
**自助操作限制**：查看自己的账户时，只有 **Rename user** 操作可用。你不能编辑自己的角色、从管理端重置自己的密码、禁用或删除自己的账户。
</Note>

<Note>
**非管理员用户**无法重命名其他用户。重命名操作仅对 admin 和 owner 可用。
</Note>

### 编辑角色和团队

编辑抽屉面板允许你修改角色和团队成员归属。对于 owner，它会改为显示一条说明，告知 owner 角色是固定的，没有任何可更改的内容。

### 重置密码

设置一个新的临时密码（至少 8 个字符）。用户必须重新登录，并应在「设置」中选择自己的密码。

### 禁用与删除的区别

- **禁用（Disable）** 是可逆的，被禁用的用户无法登录，但你可以随时重新启用他们。
- **删除（Delete）** 是永久性的，它会移除账户及其所有会话。审计历史中仍会保留该用户名下的记录，但账户无法恢复。

这两项操作都会先要求确认。
