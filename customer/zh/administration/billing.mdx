计费位于 **Settings → Admin → Billing（设置 → 管理 → 计费）**。

在此查看方案、当前采集器用量、推荐积分与发票历史。新客户定价见 [hilt.ai](https://hilt.ai) — 本页为现有租户的产品内计费界面。

---

## 可见内容

计费页分为三个区域：

### 采集器用量

主卡片展示计量方式：

- **In use now（当前使用）** — 当前正在上报遥测的采集器数量
- **Billed peak（计费峰值）** — 当前合同期内达到的最高并发采集器数；年度发票以此为准
- **Annual（年度）** — 按计费峰值计算的合同期总金额（根据角色，金额可能在界面中脱敏）

用量条对比当前使用与计费峰值。下方月度图表展示年内并发采集器峰值趋势 — 最高柱即为开票依据。

计费按合同期内的**峰值并发采集器数**计量，而非日均主机数或存储容量。Linux 采集器、macOS 采集器及其他已注册数据源在活跃时均计为一个采集器。

### 方案（Plan）

显示当前方案层级（例如 **Business** 或 **Enterprise**）。若为 Business，可能显示 Enterprise 升级选项及联系销售操作。

方案名称与权益在签约时确定。变更层级或扩容请联系客户团队。

### 推荐（Referrals）

若组织参与 Hilt 推荐计划，推荐卡片跟踪已介绍公司、管线阶段及计入账户的积分（例如试点月份积分，或推荐方成为客户后的采集器积分）。

### 发票历史

表格列出历史发票与贷项：

| 列 | 含义 |
| :-- | :-- |
| **Invoice** | 发票或贷项参考编号 |
| **Issued** | 开具日期 |
| **Service period** | 费用覆盖的合同窗口 |
| **Data collectors** | 该行对应的采集器数量（年度、按比例增量或贷项说明） |
| **Amount** | 费用或贷项金额 |
| **Status** | 支付状态（例如 **Paid** 或 **Credited**） |

合同期内中途扩容会以按比例发票体现增量采集器至期末的费用。

## 计费页不包含的内容

**遥测存储** 在 **Settings → Admin → Storage（设置 → 管理 → 存储）** 的 [存储](/zh/administration/storage) 页单独跟踪。存储页展示热/冷层用量、日增长、各数据集保留与生命周期策略 — 属于运维容量视图，而非订阅发票。

自有云账户中的基础设施费用（BYOC 部署的计算、数据库、对象存储）不在本计费页内。请参阅云厂商成本工具与 Hilt 协议。

---

## 权限

计费需要管理员角色。无管理员权限的用户在设置中看不到计费部分。

---

## 新客户与定价

Hilt 定价为商业定价，取决于部署规模、方案层级与合同期限。产品文档不公布价目表。

- 访问 [hilt.ai](https://hilt.ai) 了解产品与定价咨询
- 联系 Hilt 客户代表获取报价、扩容与合同变更
