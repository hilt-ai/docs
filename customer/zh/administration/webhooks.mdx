Webhooks 位于 **Settings → Integrations**，与 Slack 和 Google Workspace 并列。

用于将发现与告警推送到自有接收端。请求形状与示例见 [Webhooks API](/zh/api/webhooks)。

1. 打开 [设置](/zh/dashboard/settings) → **Integrations** → **Webhooks**
2. 添加端点 URL 并选择事件类型
3. 用接收端日志或 API 示例验证投递
