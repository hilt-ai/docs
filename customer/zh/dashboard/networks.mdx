网络页展示主机如何与目的地通信。使用 **Linux | macOS** 范围切换。

---

## Linux 范围

模式通常包括 **Fleet / Timeline / Graph / Map**。选中主机后可过滤 **All / Internal / External** 流量，并跳转到 [调查](/zh/dashboard/investigate)。

---

## macOS 范围

按 **应用与目的地** 的出站连接 — Sankey / 色带视图，可按字节或流数排序。每个流通过 Endpoint Security 与 Network Extension 归因到负责的应用。这吸收了旧的「网络出站」端点文档。
