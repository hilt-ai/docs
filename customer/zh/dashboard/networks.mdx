展示你的主机在网络上正在与谁通信、哪些进程连接到哪些目的地址、有多少数据在流动，以及哪些连接是新出现的或异常的。

## 页面布局

标题栏会根据你的查看范围自适应：

- **主机选择器** 和 **时间范围**（与仪表盘其余部分共享）。
- **返回链接**：当选中某台主机时，一个 **所有主机** 链接可让你回到主机群视图。
- **范围过滤器**（单主机）：**全部** / **内部** / **外部**。
- **视图切换**（单主机）：**时间线** / **图** / **地图**。
- **调查事件**：跳转到调查页面，范围限定为当前主机的网络活动。

### 信号概要

一条概要带突出显示三类网络信号（未选中主机时为全主机群范围的计数，否则为主机级别的计数）：

| 信号 | 含义 |
| --- | --- |
| **新进程** | 在此窗口内首次在网络上进行通信的进程 |
| **新目的地址** | 被某个已知进程首次联系的 IP 地址 |
| **流量峰值** | 与基线相比，传输字节数出现异常增长 |

## 主机群视图

在未选中任何主机时，页面会展示跨主机的网络活动：一个主机名册侧边栏，旁边是一张连接图。

### 对比主机侧边栏

列出范围内的主机，点击可聚焦高亮，再次点击可清除。它有自己的搜索框（按 `/` 聚焦），每一行会显示主机标签、状态、信号计数和流量计数。点击某台主机会将其聚焦高亮并使图居中；再次点击则清除高亮。

### 连接图

该图绘制出各主机以及它们共享的目的地址，并附带一条工具栏概要（`N hosts · N destination addresses · N cross-host connections`）。在大型主机群上，你可以在 **概览** 和 **显示目的地址** 之间切换。图例区分了 **Host**、**Destination** 和 **Shared**（边）元素，当某台主机被聚焦高亮时，导航面板会提供 **适应全部** 和 **活跃主机**。

### 详情面板

点击某个节点或边，会从右侧滑入一个详情面板：

| 选中对象 | 关键字段 |
| --- | --- |
| **连接**（边） | 主机对、连接数、A→B 和 B→A 的字节数，以及 **进程对**（进行通信的命令、应用、身份和字节数） |
| **主机**（节点） | 目的地址、流量、出站字节数、对端；热门目的地址、进程和跨节点对端；外加跳转到该主机 **时间线 / 图 / 地图** 的按钮 |
| **目的地址**（节点） | 主机名/地址、各主机的端口胶囊、流量、出站/入站字节数，以及涉及的进程 |

## 单主机视图

选中某台主机后，主区域会根据 **视图** 切换开关而改变。**范围** 过滤器（全部 / 内部 / 外部）对这三种视图均生效。

### 时间线

默认的单主机视图。每一行是一个进程（`comm`），按活动时长排序：

- **Y 轴** 列出进程；**X 轴** 是所选时间范围。
- 每一行绘制一条活动条（从首次出现到最后出现），并带有目的地址标记。
- **信号标记** 会在时间线上标出事件：新进程、新目的地址和流量峰值。
- 点击某一行可打开进程详情面板；点击某个标记可在打开面板时预先选中对应的目的地址。

如果所有流量都处于正常模式内（或范围内没有任何流量事件），视图会显示空状态。

### 图

一张以主机为中心的径向图：进程以方块形式向外辐射，目的地址被归入各个集群。

- 在 **已标记** 和 **全部流量** 之间切换。
- **搜索节点** 可按进程或目的地址过滤。
- 图例涵盖新进程、新目的地址、流量峰值和正常。
- 点击某个进程可打开其详情面板；点击某个集群可检查其目的地址。还提供一个全屏切换开关。

### 地图

一张世界地图，按地理位置放置目的地址标记。点击某个标记会打开一个位置面板，显示城市/国家、目的地址数量、字节数、流量计数、相关时的流量峰值徽章，以及一个可展开的目的地址及其进程列表。

## 进程详情面板

进程详情面板由时间线和图视图共享，用于拆解单个进程的网络活动：

| 区域 | 内容 |
| --- | --- |
| **标题** | 返回进程列表、命令、当存在多个实例时的实例选择器、一条概要（`N dest · N flows · bytes out · bytes in · duration`），以及一个调查链接 |
| **字节图** | 随时间变化的发送字节数（蓝色）和接收字节数（绿色） |
| **上下文** | 所选 `host:port` 的流量，或提示你挑选一个目的地址 |
| **目的地址表格** | 目的地址（旗标、主机名、地理位置）、端口（含服务）、出站、入站、流量，以及 **信号**（新进程 / 新目的地址 / 流量峰值） |
