凭据页展示 **macOS** 端点上哪些应用访问了哪些机密与隐私敏感资源。无 Linux 范围切换；若无 macOS 采集器上报，页面为空。

本页吸收了旧的端点「凭据访问」与「凭据与隐私」文档。

---

## 类别

| 类别 | 示例 |
| --- | --- |
| **Camera / mic** | TCC 保护的采集设备 |
| **Keychain** | 钥匙串查询与文件访问 |
| **Browser** | 密码与 Cookie 存储 |
| **Cloud credentials** | 云 CLI / SDK 凭据路径 |
| **SSH** | `~/.ssh` 及相关材料 |
| **Privilege** | sudo / 提权 |
| **dotenv** | 本地环境 / 密钥文件 |

每次访问都带有负责应用及可用的代码签名信任信息。
