总览是登录后的落地页。它是覆盖整个舰队（Linux 与 macOS 一并展示，无范围切换）的可定制组件网格。

---

## 默认组件

| 组件 | 内容 |
| --- | --- |
| **Events analyzed** | 所选窗口内的遥测量 |
| **Monitored hosts** | 正在上报的采集器 |
| **Users tracked** | 近期有活动的身份 |
| **Security impact** | 高层风险 / 影响摘要 |
| **Threat profile** | 发现类型或严重度分布 |
| **Recent findings** | 待审阅的最新异常与告警 |

---

## 编辑模式

可添加、移除组件，或重置为默认布局。其他组件可能包括主机状态、Top talkers、文件变更、未关闭异常与检测规则活动。
