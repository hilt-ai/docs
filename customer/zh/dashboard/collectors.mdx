采集器页是所有 Hilt agent 的舰队清单。Linux（eBPF）与 macOS（Endpoint Security）主机出现在同一张表中。

---

## 舰队摘要

| 筛选 | 含义 |
| --- | --- |
| **All Hosts** | 完整名册 |
| **Active** | 近期可见 / 健康 |
| **Offline** | 过期或失效的采集器 |

摘要计数合并 Linux 存活/过期/失效与 macOS 端点健康。

---

## 主机表

可按名称、状态与最后可见时间搜索。选择一行打开 **主机详情**（`/collectors/:hostId`）。管理员可使用 **Add Collector** 开始接入。
