Hilt 控制台与产品侧边栏一致。页面分为 **Overview（总览）**、**Collectors（采集器）**、**Data（数据）** 组、**Security（安全）** 组，以及 **Settings（设置）**。**Query** 与 **Reports** 位于顶栏（文档归在「工具」下）。

Hilt 是 **数据移动治理（Data Movement Governance, DMG）** 平台：在 Linux 与 macOS 资产上观察数据如何移动，解析身份，对行为异常打分，并支持调查与遏制。

---

## 总览与采集器

- [总览](/zh/dashboard/overview)：可编辑的首页组件，展示舰队健康与近期发现
- [采集器](/zh/dashboard/collectors)：Linux 与 macOS 采集器列表及主机详情

---

## 数据

多个数据中心页使用 **Linux | macOS** 范围切换。Linux 对应 eBPF / 云工作负载遥测；macOS 对应 Endpoint Security 遥测。

- [调查](/zh/dashboard/investigate)：带过滤器与时间线的事件深潜
- [血缘](/zh/dashboard/data-lineage)：进程与数据流图（Linux）或基于 exec 的进程血缘（macOS）
- [网络](/zh/dashboard/networks)：舰队网络信号（Linux）或应用→目的地出站（macOS）
- [文件](/zh/dashboard/files)：文件遥测与路径浏览器；macOS 含可移动介质
- [用户](/zh/dashboard/users)：用户时间线 — 跨舰队的身份活动
- [活动](/zh/dashboard/activity)：按应用的文件操作（上传、创建、删除、编辑）
- [凭据](/zh/dashboard/credentials)：macOS 端点上的凭据与隐私访问

---

## 安全

- [异常](/zh/dashboard/anomalies)：ML 发现队列与异常窗口（行为抑制）
- [告警](/zh/dashboard/alerts)：规则命中队列、自定义规则与敏感路径
- [暴露面](/zh/dashboard/exposure)：第三方依赖景观与干预策略
- [恶意软件](/zh/dashboard/malware)：端点上的恶意软件与篡改行为
- [框架](/zh/dashboard/frameworks)：MITRE ATT&CK 与网络杀伤链覆盖
- [隔离](/zh/dashboard/quarantine)：主机隔离与爆炸半径评估

## 工具（顶栏）

- [报告](/zh/administration/reports)：高管与进程情报报告及 PDF 导出

## 设置

管理功能已并入设置。打开 [设置](/zh/dashboard/settings) 查看各标签页：

| 标签 | 内容 |
| --- | --- |
| **Account** | 个人资料、密码、会话、API 密钥 |
| **Uptime** | 推理、流水线、数据库、集成健康 |
| **System** | 模型、更新、数据导出、舰队行为 |
| **Teams** | 团队、成员、身份映射 |
| **Integrations** | Slack、Webhooks |
| **Admin** | 云数据源、计费、存储、审计日志、MCP |

macOS 设备端检测深度（持久化、篡改等）位于 [macOS 采集器 → 检测](/zh/macos-collector/detections)，不再作为侧边栏中独立的「端点」树。
