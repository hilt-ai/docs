调查是主要的事件深潜页。选定时间窗口与主机，用结构化过滤器缩小范围，并按时间阅读进程分组事件。血缘、网络、异常与用户页上的多数「调查」链接都会落到这里。

使用中心栏的 **Linux | macOS** 范围切换。Linux 显示 eBPF 事件流；macOS 显示 Endpoint Security 事件，界面骨架相同。

---

## 范围与时间

- **Linux**：来自 Linux 采集器的内核 / 进程 / 文件 / 网络遥测
- **macOS**：端点事件；另有 **User** 与 **Application** 过滤标签

时间预设与自定义范围限定调查窗口（通常最长约 24 小时）。再次点击侧边栏 **Investigate** 会重置 URL 状态。

---

## 过滤器

| 标签 | 过滤内容 |
| --- | --- |
| **Event** | 事件类型 |
| **Process** | 命令、父进程、PID、UID、用户、工作负载 |
| **Network** | IP、端口、协议、字节数 |
| **File** | 路径前缀、标志、权限 |
| **Topology** | 程序 / 会话 / 进程实例 ID |
| **Location** | 主机、boot ID、容器、Pod |
| **User / Application** | 仅 macOS |
