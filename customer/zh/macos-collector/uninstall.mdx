---

本页介绍如何移除在单台无 MDM 的 Mac 上、通过已公证 `.pkg` **独立**安装的 Hilt macOS 采集器。由于该采集器是带有篡改保护的已公证安全产品，移除过程是一段简短而审慎的步骤：先**关闭**其扩展、**重启**，再**删除**应用。

<Note>
以下步骤需要**在 Mac 上以管理员身份操作**。关闭安全扩展需要本地管理员进行身份验证；Apple 不允许静默完成此操作。
</Note>

<Note>
以下步骤针对 **macOS 15 (Sequoia)** 编写。在 macOS 13 或 14 上界面布局类似，但扩展位于**系统设置 → 隐私与安全性**下，而非**登录项与扩展**。
</Note>

## Stop data collection right now

如果你只需要让采集器**立即停止捕获**——无论是在完整卸载之前，还是替代完整卸载——请关闭它的两个扩展。

<Steps>
  <Step title="Open extension settings">
    前往**系统设置 → 通用 → 登录项与扩展**。
  </Step>
  <Step title="Turn off the sensor">
    在 **Endpoint Security Extensions** 下，关闭 **Hilt EDR Sensor**。
  </Step>
  <Step title="Turn off the network filter">
    在 **Network Extensions** 下，关闭 **Hilt EDR Network Filter**。出现提示时输入管理员密码。
  </Step>
</Steps>

两者都关闭后，采集即会停止。若要彻底移除采集器，请继续以下步骤。

## Remove the collector

移除采集器需要管理员账户。最后一步会用到 **Terminal** 和 `sudo`。请按顺序执行各步骤。

<Warning>
不要先删除应用。采集器运行时会保护自身文件，因此在关闭其扩展之前删除应用会被设计机制阻止（并记录为一次篡改事件）。请先关闭扩展并重启，以安全地停用该保护，然后再移除以下所有内容。
</Warning>

<Steps>
  <Step title="Turn off both extensions">
    按 [Stop data collection](#stop-data-collection-right-now) 中所示，关闭 **Hilt EDR Sensor** 和 **Hilt EDR Network Filter**。这会停止采集并停用自我保护。
  </Step>
  <Step title="Restart the Mac">
    重启以使安全扩展完全关闭。
  </Step>
  <Step title="Remove the app and its background service">
    打开 **Terminal** 并运行以下命令。第一条命令会停止负责发送传感器遥测的转发器 LaunchDaemon；其余命令会移除其启动项、应用及其支持文件。

    ```bash
    # Stop the forwarder (root LaunchDaemon)
    sudo launchctl bootout system/com.hilt.edr.forwarder 2>/dev/null

    # Remove the launch item, the app, and its support files
    sudo rm -f /Library/LaunchDaemons/com.hilt.edr.forwarder.plist
    sudo rm -rf /Applications/EDRApp.app "/Library/Application Support/Hilt"
    ```

    出现提示时输入管理员密码。
  </Step>
  <Step title="Restart once more">
    再次重启以完成移除这两个系统扩展。在此次重启之前，它们仍会显示但处于非活动状态。它们已被关闭，不再采集任何内容。
  </Step>
</Steps>

## Confirm it's removed

在 **Terminal** 中运行以下命令。每条都不返回任何内容；`ls` 检查也可能改为打印 “No such file or directory”：

```bash
systemextensionsctl list | grep -i hilt                       # no Hilt extensions
sudo launchctl list | grep -i hilt                            # no Hilt services
ls /Library/LaunchDaemons/com.hilt.edr.* \
   /Library/LaunchAgents/com.hilt.edr.* 2>/dev/null           # no launch items
ls -d /Applications/EDRApp.app "/Library/Application Support/Hilt" 2>/dev/null   # gone
```

<Note>
移除后不久，`systemextensionsctl list` 可能仍会列出这两个扩展（显示为 `[activated disabled]` 或等待卸载）。这属于正常现象。它们已被关闭、不再运行任何内容，并会在下次重启时完全注销。
</Note>

可选：在**系统设置 → 隐私与安全性 → Full Disk Access** 下移除残留的 **Hilt EDR Sensor** 条目。应用移除后，该条目已失效。

## What happens to data already collected

卸载会立即停止所有新的采集。已发送到你的 Hilt 环境的遥测数据，将按照你与 Hilt 的协议予以保留。若要查看已采集的内容或请求删除，请联系 Hilt。

## Need help

请联系你的 Hilt 对接人或发送邮件至 **support@hilt.ai**。如果移除过程中出现任何异常情况，请附上该 Mac 的型号和 macOS 版本，我们会协助你完成。
