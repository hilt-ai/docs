---
title: "配置参考"
description: "DMG 采集器的 CLI 标志、环境变量与配置文件键。"
---

代理通过以下方式接受配置（按优先级排序）：CLI 标志、环境变量，以及 `/etc/dag-agent/config.yaml`。

| CLI | 环境变量 | 配置键 | 默认值 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| `-s` | `DAG_SHIP_URL` | `ship_url` | 未设置 = 文件模式 | HTTPS 采集器 URL。 |
| `-o` | `DAG_OUTPUT_PATH` | `output_path` | `/var/log/dag-agent/events.jsonl` | JSONL 输出。设为 `-` 可显式输出到 stdout。 |
| `-n` | `DAG_NODE_ID` | `node_id` | `$(hostname)` / K8s 上为 `spec.nodeName` | 在仪表盘上显示的字符串主机标签。 |
| `-b` | n/a | n/a | 关闭 | 基准测试模式；仅发送。 |
| `-v` | n/a | n/a | 关闭 | 详细模式：将事件镜像输出到 stderr。 |
| `-V` | n/a | n/a | n/a | 打印版本并退出。 |
| n/a | n/a | `cpu_limit` | 无限制 | 在 systemd drop-in 中写入为 `CPUQuota=`。 |
| n/a | n/a | `ram_limit` | 无限制 | 在 systemd drop-in 中写入为 `MemoryMax=`。 |
| n/a | n/a | `ringbuf_size` | `1M` | 每 CPU 的 BPF 环形缓冲区大小。在繁忙主机上增大（`8M`、`16M`）。 |
| n/a | n/a | `tag_refresh_interval_s` | `1800`（30 分钟） | 重新拉取云实例元数据标签的间隔，无需重启代理。设为 `0` 可禁用周期性拉取；执行 `systemctl reload` 始终会立即触发一次刷新。适用于 EC2 和 EKS（需在实例/启动模板上启用 `instance_metadata_tags`）。 |
