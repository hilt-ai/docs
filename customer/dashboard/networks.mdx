Networks shows how hosts talk to destinations. Use the **Linux | macOS** scope toggle.

---

## Linux scope

Subtitle style: `N hosts · M signals`.

Modes typically include:

| Mode | What you see |
| --- | --- |
| **Fleet** | New processes, destinations, and volume spikes across hosts |
| **Timeline** | Network activity over time |
| **Graph** | Connection topology |
| **Map** | Geographic or logical map of destinations |

On a selected host you can filter **All / Internal / External** traffic. Pivot into [Investigate](/dashboard/investigate) for the underlying flows.

---

## macOS scope

Outbound connections by **application and destination** — Sankey / ribbon views ranking by bytes or flow count. Every flow is attributed to the responsible app via Endpoint Security and the Network Extension path.

This absorbs the former “Network Egress” endpoint documentation.
