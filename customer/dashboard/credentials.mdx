Credentials shows which applications accessed which secrets and privacy-sensitive resources on **macOS** endpoints. There is no Linux scope toggle; if no macOS collectors are reporting, the page is empty.

Subtitle in product: *Which applications accessed which credentials — keychain, browser passwords, cloud credentials, SSH, sudo, camera & microphone*.

This page absorbs the former Endpoint **Credential Access** and **Credential & Privacy** docs.

---

## Categories

Filter by category and application list, with a time-window control:

| Category | Examples |
| --- | --- |
| **Camera / mic** | TCC-protected capture devices |
| **Keychain** | Queries and keychain file access |
| **Browser** | Password and cookie stores |
| **Cloud credentials** | Cloud CLI / SDK credential paths |
| **SSH** | `~/.ssh` and related material |
| **Privilege** | sudo / elevation |
| **dotenv** | Local env / secret files |

Every access carries the responsible app and code-signing trust where available so routine signed use reads differently from unsigned theft.
