Investigate is the primary event deep-dive. Scope a time window and hosts, narrow with structured filters, and read process-grouped events chronologically. Most “investigate” links from Lineage, Networks, Anomalies, and Users land here.

Use the **Linux | macOS** scope toggle in the hub bar. Linux shows the eBPF event stream; macOS shows Endpoint Security events with the same chrome.

---

## Scope and time

- **Linux**: kernel/process/file/network telemetry from the Linux collector
- **macOS**: endpoint events; subtitle reflects macOS event counts; extra filter tabs for **User** and **Application**

Time presets and a custom range bound the investigation. The page enforces a practical maximum window (typically 24 hours). Fresh visits often auto-select active hosts.

Re-clicking **Investigate** in the sidebar resets URL state and remounts a clean view.

---

## Filters

Filter tabs across the header:

| Tab | What you filter on |
| --- | --- |
| **Event** | Event types (process, files, network, workloads) |
| **Process** | Command, parent, PIDs, UID, user, workload |
| **Network** | IPs, ports, protocol, bytes |
| **File** | Path prefix, flags, permissions |
| **Topology** | Program / session / process instance IDs |
| **Location** | Hosts, boot ID, container, pod |
| **User / Application** | macOS only |

Active filters appear as removable chips. Context banners appear when you arrive from Lineage, Networks, Sessions, or Files.

---

## Timeline and event list

An **Activity** histogram sits above the list. Drag to zoom; amber bands mark windows that overlap anomaly findings. Events load in batches; expand a row for forensic fields and pivots into Connections, Files, or Lineage.
