Activity (route `/file-upload-detection`) shows **file actions by application** — uploads, creates, deletes, and edits across the fleet.

This is not the Users page and not the raw Investigate event stream.

---

## Filters

| Control | Purpose |
| --- | --- |
| **Applications** | Narrow to specific apps |
| **Actions** | Upload, create, delete, edit |
| **Sort** | Newest or oldest |
| **Time** | Window presets |

---

## Table and detail

Rows are fleet file-action alerts. Open a row for a detail drawer with host, path, actor, and timing. Use that context to continue in [Investigate](/dashboard/investigate) or [Files](/dashboard/files).
