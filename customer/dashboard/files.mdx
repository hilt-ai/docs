Files is the fleet file explorer. Use the **Linux | macOS** scope toggle.

---

## Linux scope

Title: **Files**. Browse hosts that report file opens, writes, renames, and deletes. Drill from fleet overview into a host path browser and per-file detail, then into [Investigate](/dashboard/investigate) for the responsible process.

---

## macOS scope

Title may show as **Endpoint Files**. Telemetry comes from `endpoint_events` with code-signing provenance: where a file came from, who wrote it, and whether quarantine flags were stripped.

### Removable media

On macOS, the Files hub includes **removable media** context (USB / volumes / AirDrop-related activity). Mounts and writes under `/Volumes` are attributed to the application that performed them. This replaces the old standalone Removable Media page.
