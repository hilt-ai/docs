Settings is a single hub with horizontal tabs. Former Admin pages live here — there is no separate Admin sidebar section.

Open **Settings** from the gear in the sidebar footer.

---

## Tabs

| Tab | What it covers | Docs |
| --- | --- | --- |
| **Account** | Profile, password, sessions, API keys | [Account](/dashboard/settings-account) |
| **Uptime** | Inference, Pipeline, Databases, Integrations health | [System Status](/administration/system-status), [Prometheus](/administration/prometheus) |
| **System** | Models, Updates, Data Export, Fleet Behavior | [Models](/on-prem/model-lifecycle), [Auto-Update](/on-prem/auto-update-overview), [Data Export](/on-prem/data-export-overview), [Fleet Behavior](/dashboard/fleet-behavior) |
| **Teams** | Teams, Members, Identity mapping | [Teams](/administration/teams), [Members](/administration/user-management), [Identity mapping](/administration/identity-mappings) |
| **Integrations** | Slack, Google Workspace, Webhooks | [Slack](/administration/slack-notifications), [Google Workspace](/administration/google-workspace), [Webhooks](/administration/webhooks) |
| **Admin** | Cloud Sources, Billing, Storage, Audit Log | [Cloud Sources](/administration/cloud-sources), [Billing](/administration/billing), [Storage](/administration/storage), [Audit Log](/administration/audit-log), [ClickHouse](/administration/clickhouse-tables), [MCP](/dashboard/mcp-server) |

Uptime sections in the product rail: **Inference** (LLM narratives, cluster labeling, query), **Pipeline** (enrichment, TRACE), **Databases** (ClickHouse and Postgres), **Integrations** (Slack delivery health).

System shows an auto-update status strip when release endpoints are available.
