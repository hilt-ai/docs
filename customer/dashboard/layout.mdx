The Hilt console mirrors the product sidebar. Pages fall into **Overview**, **Collectors**, a **Data** group, a **Security** group, then **Settings**. **Query** and **Reports** live in the top bar (documented under Tools).

Hilt is a **Data Movement Governance (DMG)** platform: it watches how data moves across Linux and macOS estates, resolves identity, scores behavioral anomalies, and supports investigation and containment.

---

## Overview and Collectors

- [Overview](/dashboard/overview): customizable home widgets for fleet health, findings, and threat profile
- [Collectors](/dashboard/collectors): fleet list of Linux and macOS collectors and per-host detail

---

## Data

Several Data hubs use a **Linux | macOS** scope toggle. Linux covers eBPF / cloud-workload telemetry; macOS covers Endpoint Security telemetry. The toggle is global for that session.

- [Investigate](/dashboard/investigate): time-bounded event investigation with filters and timeline
- [Lineage](/dashboard/data-lineage): process and data-flow graphs (Linux) or exec-based process lineage (macOS)
- [Networks](/dashboard/networks): fleet network signals (Linux) or app→destination egress (macOS)
- [Files](/dashboard/files): file telemetry and path explorer; macOS includes removable media
- [Users](/dashboard/users): User Timeline — identity activity across the fleet
- [Activity](/dashboard/activity): file actions by application (uploads, creates, deletes, edits)
- [Credentials](/dashboard/credentials): credential and privacy access on macOS endpoints

---

## Security

- [Anomalies](/dashboard/anomalies): ML finding queue and Anomaly Windows (behavioral suppression)
- [Alerts](/dashboard/alerts): rule-break queue, custom Rules, and Sensitivity paths
- [Exposure](/dashboard/exposure): third-party dependency landscape and intervention policy
- [Malware](/dashboard/malware): malware and tamper behavior on endpoints
- [Frameworks](/dashboard/frameworks): MITRE ATT&CK and Cyber Kill Chain coverage
- [Quarantine](/dashboard/quarantine): host isolation and blast-radius assessment

---

## Tools (top bar)

- [Query](/dashboard/query): natural-language assistant over telemetry and docs
- [Reports](/administration/reports): executive and process-intel reports with PDF export

---

## Settings

Admin is folded into Settings. Open [Settings](/dashboard/settings) for the map of tabs:

| Tab | Sections |
| --- | --- |
| **Account** | Profile, password, sessions, API keys |
| **Uptime** | Inference, Pipeline, Databases, Integrations health |
| **System** | Models, Updates, Data Export, Fleet Behavior |
| **Teams** | Teams, Members, Identity mapping |
| **Integrations** | Slack, Google Workspace, Webhooks |
| **Admin** | Cloud Sources, Billing, Storage, Audit Log, MCP |

On-device macOS detection depth (persistence, tamper, and related rule families) lives under [macOS Collector → Detections](/macos-collector/detections), not as a separate Endpoint tree in the sidebar.
