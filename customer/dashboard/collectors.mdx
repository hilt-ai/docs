Collectors is the fleet inventory for every Hilt agent. Linux (eBPF) and macOS (Endpoint Security) hosts appear in one table.

---

## Fleet summary

Radios at the top filter the table:

| Filter | Meaning |
| --- | --- |
| **All Hosts** | Full roster |
| **Active** | Recently seen / healthy |
| **Offline** | Stale or dead collectors |

Summary counts combine Linux alive/stale/dead with macOS endpoint health.

---

## Host table

Search and scan hosts by name, status, and last-seen. Select a row to open **host detail** (`/collectors/:hostId`) for that collector's identity, configuration context, and recent activity.

Admins can use **Add Collector** to start onboarding another host or estate.
