Lineage answers *who launched what* and how data moved between processes. Use the **Linux | macOS** scope toggle — the two estates share the hub but render different graphs.

---

## Linux scope

Title: **Data Lineage**. Subtitle summarizes hosts, relationships, and related anomalies.

When a host is selected you can switch:

| View | Purpose |
| --- | --- |
| **Data Flow** | Process and data topology for the host |
| **Sessions** | Session-oriented graphs |

Without a host focused, you see a fleet overview of relationships. Drill into a node to continue in [Investigate](/dashboard/investigate).

---

## macOS scope

Title remains **Data Lineage**; the graph is built from Endpoint Security `exec` / fork telemetry — every process spawn the kernel sees, with code-signing trust on edges where available.

This replaces the older standalone “Process Lineage” endpoint page. Focus a Mac from the collector sidebar or host picker to narrow the graph.
