## Prerequisites

- macOS or Linux (team standard)
- Docker and Docker Compose
- Go 1.22+ (backend, enrichment, query)
- Node.js 20 LTS and npm (frontend, Mintlify docs preview)
- Python 3.12 (detection ML)
- Access to required secrets and cloud dev accounts

## Getting the Code

Clone the repo you need from the `hilt-ai` GitHub organization:

```bash
git clone git@github.com:hilt-ai/dag-backend.git
cd dag-backend
```

Repeat for other repos as needed. Each repository's README should list service-specific setup steps.

Branch convention: feature branches off `dev` for application repos; docs repo uses `main` with feature branches merged via PR.

## Running Locally

Local setup varies by service. Common patterns:

- Backend: environment file from team vault, `docker compose up`, then run the Go service.
- Frontend: install dependencies, point API URL at local or dev backend, start dev server.
- Infra: Terraform workspaces in `cybe-dag-infra` for non-local environments.

Check the target repo's README before assuming a single shared dev stack.

**Detection ML:** Python setup, `.env` from `.env.example`, and Makefile smoke targets. See [Local ML Development](/detection-ml/local-development).

## Common Tasks

- Run tests: see repo Makefile or README (`go test ./...`, `pytest`, `npm run test`)
- Lint/format: follow repo CI configuration
- Deploy to dev: coordinate with infra docs in `cybe-dag-infra`
