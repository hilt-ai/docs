Welcome to Hilt engineering. This page is a starting point when you're joining a new team or repo.

## Prerequisites

- GitHub access to the `hilt-ai` organization
- Cloud and secrets access as required by your team
- Local tooling: Git, Docker, Go, Node.js, and Python (versions vary by repo)

## Repo Overview

| Repo | Description |
| --- | --- |
| `data-access-governance` | eBPF telemetry agent (Linux; Fargate via seccomp+ptrace) |
| `macos-edr-agent` | macOS Endpoint Security agent (ESensor + NetFilter) |
| `edr-collector` | macOS EDR ingest service |
| `dag-backend` | Core backend API and platform services |
| `dag-frontend` | Customer-facing web dashboard |
| `dag-enrichment` | Streaming enrichment, tokens, baselines, GNN edges |
| `dag-detectionML` | TRACE prod scoring + offline training (TRACE, GNN) |
| `dag-query` | Query layer and MCP tools |
| `dag-tokenspec` | Token vocabulary contract for TRACE |
| `cybe-dag-infra` | Infrastructure, ClickHouse migrations, Terraform |

## First Day Checklist

1. Get GitHub org access and join the relevant Slack channels.
2. Clone the repo you'll work on and read its README.
3. Set up local development using [Dev Environment](/dev-environment).
4. Skim [Architecture](/architecture) for how services connect.
5. **ML engineers:** read [Detection ML Overview](/detection-ml/overview) and run smoke tests per [Local Development](/detection-ml/local-development).
6. Pair with your team lead on a first small task or bug fix.
