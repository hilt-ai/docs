</Note>

Hilt 的 MacOS 端点覆盖使用 Apple Endpoint Security 框架和托管的 Chrome 扩展，将数据检测与响应扩展到 MacOS 端点，作为覆盖您服务器基础设施的 Linux 采集器的补充。

正式发布后，本页面将介绍如何预配 MacOS 端点，包括通过 MDM 部署系统扩展和 Chrome 扩展。有关 MacOS 采集器当前的功能，请参阅 [MacOS 采集器](/zh/macos-collector)。
