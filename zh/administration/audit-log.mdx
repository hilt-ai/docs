账户活动的审计追踪。审计日志记录身份验证事件和管理操作（谁、做了什么、在何时），将其归组为按用户划分的会话，并允许你按时间、用户名和操作类型进行筛选。本页面需要 **view audit** 权限。

<Note>
审计日志目前仅在演示后端上可访问。在正式部署环境中，该路由会重定向到[概览](/zh/dashboard/overview)。当 `/admin/audit` 接口可用时，本页面会读取真实数据，因此它记录的是一项真实功能，而非占位界面。
</Note>

---

## 页头

页头显示标题 **Audit Log** 和副标题 _"Authentication and administrative actions grouped by session"_，右侧带有时间范围切换控件。

### 时间范围

分段切换控件用于将日志限定到近期活动：

| 选项 | 时间窗口 |
| --- | --- |
| **All time** | 不限时间 |
| **5m** | 最近 5 分钟 |
| **15m** | 最近 15 分钟 |
| **1h** | 最近 1 小时 |
| **6h** | 最近 6 小时 |
| **24h** | 最近 24 小时（默认） |

该时间窗口以当前时间为锚点，并会自动刷新。

---

## 筛选栏

页头下方有一个筛选栏，用于缩小展示范围：

- **Search by username**：一个文本框，按不区分大小写的子串匹配用户名。输入会经过防抖处理后再生效。
- **操作筛选（Action filter）**：一个下拉菜单，默认为 **All actions**。选择单一操作后，仅保留包含至少一条该类型记录的会话（参见[操作类型](#操作类型)）。
- 计数摘要显示为 _"{n} sessions · {n} entries"_，会随当前筛选条件变化。

列表每 30 秒刷新一次，并在任何筛选条件变更后刷新。

## 会话列表

记录会按用户归组为会话。一个会话通常从 **login** 持续到对应的 **logout**；尚未关闭的 login 会显示为仍处于活动状态，而没有登录锚点的管理操作则会被收集到单独的 **Admin actions** 分组中。会话按时间从新到旧排序，最上方的会话默认展开。

### 会话页头

每个会话是一张卡片。页头行显示：

- 一个圆形**头像**，显示用户名首字母。
- **用户名**。
- 一个**状态徽章**：

| 徽章 | 含义 |
| --- | --- |
| _Active_ | 会话有 login 但尚无 logout |
| _Ended_ | 会话同时有 login 和 logout |
| _Admin actions_ | 没有登录锚点的管理操作 |

- 一个**相对时间**（例如 _"2h ago"_），正常会话前带登录图标，**Admin actions** 分组前带时钟图标。
- 折叠状态下，会显示一条内联**事件条**：从左到右排列的彩色圆点和简短操作标签，用于概括该会话的记录。

点击页头任意位置可展开或折叠会话。

### 会话时间线

展开会话后，会显示该会话记录的纵向时间线，按时间顺序排列。每条记录显示：

- 一个**操作徽章**，按操作类型着色。
- 一个等宽字体的**时间戳**（时:分:秒）。
- 一行可选的**详情（detail）**，描述该操作。

当会话跨越多天时，会出现一个**日期分隔符**（例如 _Today_、_Yesterday_，或「星期-月-日」格式的标签），标记日期发生变化的位置。

## 操作类型

每条记录都带有一个操作。操作筛选器和徽章使用以下类型：

| 操作 | 分组 |
| --- | --- |
| _Login_ | 身份验证 |
| _Logout_ | 身份验证 |
| _Run query_ | 分析师活动 |
| _View report_ | 分析师活动 |
| _View investigation_ | 分析师活动 |
| _Acknowledge alert_ | 分析师活动 |
| _Export data_ | 分析师活动 |
| _Create user_ | 管理操作 |
| _Update user_ | 管理操作 |
| _Reset password_ | 管理操作 |
| _Delete user_ | 管理操作 |
| _Create team_ | 管理操作 |
| _Update team_ | 管理操作 |
| _Delete team_ | 管理操作 |
| _Set team nodes_ | 管理操作 |

折叠状态的事件条和展开后的时间线徽章使用一致的配色，因此同一操作在任何位置看起来都相同。这些管理操作对应于[用户管理](/zh/administration/user-management)和[团队](/zh/administration/teams)页面上的操作。

## 状态

- **加载中**：日志加载期间显示居中的加载动画。
- **空状态**：当没有任何记录匹配当前的时间范围、用户名和操作筛选条件时，显示一个盾牌图标和 _"No sessions match your filters."_。
