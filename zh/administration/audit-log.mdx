审计日志记录仪表盘中执行的每一次身份验证事件和管理操作。条目按用户会话分组，以便你查看每个用户在一次登录期间执行的完整操作序列。本页面需要 **view audit** 权限。

---

## 会话

每张会话卡片显示：

- **用户名**和头像首字母。
- **状态徽标**：Active（当前已登录）、Ended（已登出）或 Admin actions（在当前时间窗口内没有对应登录记录的管理操作）。
- **登录时间**，以相对时间戳显示。
- **事件条**（折叠状态）：一条由彩色圆点和标签组成的水平链，可一目了然地显示该会话中的操作。

点击会话卡片可展开其完整时间线。页面加载时会**自动展开第一个会话**。

### 展开的时间线

展开视图按时间顺序显示每个操作，包含：

- 与操作类型对应的彩色**圆点**。
- **操作徽标**（例如 Login、Run Query、Create User）。
- 以本地时间显示的**时间戳**。
- 可用时显示的**详细文本**（例如执行的查询、创建的用户）。

当会话跨越多个日历日时，会出现日期分隔符。

## 操作类型

| 操作 | 类别 | 说明 |
| --- | --- | --- |
| **Login** | Auth | 用户登录 |
| **Logout** | Auth | 用户登出 |
| **Run query** | Analyst | 在 Query 页面执行了查询 |
| **View report** | Analyst | 打开或生成了报告 |
| **View investigation** | Analyst | 打开了 Investigate 页面 |
| **Acknowledge alert** | Analyst | 对异常发现项进行了分诊 |
| **Export data** | Analyst | 从仪表盘导出了数据 |
| **Create user** | Admin | 创建了新的仪表盘用户 |
| **Update user** | Admin | 更改了用户的角色或团队 |
| **Reset password** | Admin | 重置了其他用户的密码 |
| **Delete user** | Admin | 永久移除了用户账户 |
| **Create team** | Admin | 创建了新团队 |
| **Update team** | Admin | 更改了团队设置 |
| **Delete team** | Admin | 移除了团队 |
| **Set team nodes** | Admin | 更改了团队可查看的主机 |

## 筛选器

### 时间范围

时间窗口的分段切换器：**All time**、**5m**、**15m**、**1h**、**6h**、**24h** 或 **7d**。默认选择为 **24h**。

### 用户名搜索

按用户名筛选会话的搜索框。结果在输入时实时更新（带防抖处理）。

### 操作筛选

一个下拉菜单，用于仅显示包含特定操作类型的会话（例如仅显示用户执行了查询的会话）。

---

## 会话计数

筛选器下方，页面显示当前视图中匹配的会话数量和审计条目总数。
