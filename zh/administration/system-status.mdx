监控支撑检测与富化的各项服务的实时健康状况，了解某项服务降级的原因，并查看过去 90 天每日的可用性。本页面需要 **manage users** 权限。

页面每 60 秒自动轮询一次，因此保持标签页打开即可跟踪服务恢复情况，无需手动刷新。

---

## 页面布局

页面是一个堆叠的服务卡片列表，位于页头和状态汇总栏之下。

### 页头

- **标题：** _System Status_，副标题为 "Live health of the services behind your dashboard"。
- **checked _<时间>_**：上次获取状态的时间（在窄屏上隐藏）。
- **Refresh**：立即重新运行状态检查。获取过程中图标会旋转，按钮在完成前处于禁用状态。

### 汇总栏

页头下方的摘要条：

- **左侧：** 一个彩色圆点和总体状态标签，由最差的单项服务汇总得出（参见[总体状态](#总体状态)）。
- **右侧：** "Uptime over the past 90 days"，用于标注每张卡片上展示的每日历史记录。

### 主体状态

| 状态 | 你会看到的内容 |
| --- | --- |
| 加载中 | 首次获取期间显示居中的加载图标。 |
| 错误 | "Couldn't load system status. Try refreshing." 使用 **Refresh** 重试。 |
| 空 | 无服务上报时显示 "No services are being monitored yet."。 |
| 已加载 | 每个被监控的服务显示一张[服务卡片](#服务卡片)。 |

---

## 状态

每项服务和总体汇总都使用同一组状态。圆点颜色在汇总栏、卡片状态标签和历史柱条之间保持一致。

| 状态 | 圆点 | 含义 |
| --- | --- | --- |
| _Operational_ | 绿色 | 服务健康，正常处理中。 |
| _Degraded_ | 琥珀色 | 服务存在延迟、仅覆盖部分主机或正在恢复，会自动追赶。 |
| _Action needed_ | 红色 | 服务已停止或被阻断，需要处理或配置。 |
| _Disabled_ | 灰色 | 该服务在此部署中已关闭。 |
| _No data_ | 灰色 | 服务尚无可处理的活动，或正在等待输入。 |

### 总体状态

汇总标签反映最差的服务状态：

| 条件 | 汇总标签 |
| --- | --- |
| 所有服务正常（或无数据） | _All systems operational_ |
| 部分服务被禁用，无更差状态 | _Some services disabled_ |
| 一项服务降级或需要处理 | _1 service needs attention_ |
| 多项服务降级或需要处理 | _N services need attention_ |
| 无服务被监控 | _No services monitored_ |

## 服务卡片

每张卡片自上而下描述一项服务：

- **图标与名称：** 服务图标及其名称（例如 _Anomaly Narratives_、_Behavioral Anomaly Detection_、_Event Enrichment_）。
- **状态标签：** 该服务当前的彩色圆点和状态标签。
- **说明行：** 一句通俗易懂的描述，说明该服务的作用，或它为何降级或需要处理。
- **历史柱条：** 最多 90 个每日单元格组成的柱条，每天一个，按当天的状态着色。将鼠标悬停在某个单元格上可查看其日期，以及包含当天指标的状态摘要。监控开始之前的日期显示为 _No data_；监控开始之后的平静日期视为健康。柱条左侧标注 "90 days ago"，右侧标注 "today"。
- **页脚：** 该服务最近一次活动的时间（例如 "Last summary 4m ago"、"Last score 1m ago"、"Last enriched event 15s ago"）。若没有任何活动，在正常状态下显示 "No ... yet"，否则显示 "No recent ..."。
- **修复链接：** 当某项服务需要配置时，页脚会显示一个链接，在新标签页中打开相关帮助或设置。

### 受监控的服务

| 服务 | 跟踪内容 | 正常时的页脚 |
| --- | --- | --- |
| **Anomaly Narratives** | 为每个检测到的异常生成的通俗易懂的摘要。 | Last summary |
| **Behavioral Anomaly Detection** | 行为模型对全机群活动进行异常评分。 | Last score |
| **Event Enrichment** | 应用于事件的工作负载、会话和进程谱系富化。 | Last enriched event |

如果后端上报了仪表盘尚无专门文案的服务，该服务可能会以通用图标和 "Service status" 历史标签显示。

### 各服务的状态含义

**Anomaly Narratives**

| 状态 | 出现时机 | 说明 |
| --- | --- | --- |
| _Operational_ | 摘要正常生成。 | 对每个检测到的异常生成通俗易懂的摘要。 |
| _Degraded_ | 生成已暂停并正在重试，或正在恢复。 | 暂时不可用，自动重试中。 |
| _Action needed_ | 未配置模型，或所配置的模型不可访问。 | 需要配置模型，或在你的云账户中启用模型访问权限。请联系 Hilt 支持获取帮助。 |
| _Disabled_ | 此部署中已关闭叙述功能。 | 异常叙述已关闭。 |

**Behavioral Anomaly Detection**

| 状态 | 出现时机 | 说明 |
| --- | --- | --- |
| _Operational_ | 评分正在全机群落地。 | 行为模型正在为异常评分活动。 |
| _Degraded_ | 评分延迟或仅覆盖部分活跃主机。 | 自动追赶中。 |
| _Action needed_ | 主机活跃但没有评分落地。 | 行为检测服务可能已宕机。 |
| _Disabled_ | 行为检测已关闭。 | 在此部署中已关闭。 |
| _No data_ | 尚无可评分的主机活动。 | 等待主机活动。 |

**Event Enrichment**

| 状态 | 出现时机 | 说明 |
| --- | --- | --- |
| _Operational_ | 富化跟得上。 | 工作负载、会话和进程谱系正在被富化到你的事件中。 |
| _Degraded_ | 富化滞后，或工作负载身份缺失率偏高。 | 滞后或缺失率偏高。 |
| _Action needed_ | 事件正在到达，但富化似乎已停止。 | 工作负载身份未被应用。 |
| _Disabled_ | 富化已关闭。 | 在此部署中已关闭。 |
| _No data_ | 尚无可富化的事件。 | 等待事件。 |
