列出所有运行 Hilt 采集器的主机，显示每台主机是否正在上报数据，并支持你深入查看单台主机的遥测数据。

## 页面布局

页面纵向堆叠为两个部分：

1. **主机群概要卡片** — 顶部的三张过滤卡片。
2. **主机表格** — 可搜索、可排序的所有匹配主机列表。

点击任意一行，即可打开该主机的详情视图。

---

## 主机群概要卡片

三张卡片既是状态指示器，也是表格过滤器。同一时间只有一个过滤器处于激活状态——被选中的卡片会显示绿色边框。

| 卡片 | 数值 | 过滤范围 |
| --- | --- | --- |
| **所有主机** | 总数 | 活跃与离线主机 |
| **活跃** | 处于存活状态的主机 | 仅活跃主机 |
| **离线** | 失联 \+ 离线主机之和 | 仅离线主机 |

### 主机状态

每台主机会根据其采集器最近一次上报遥测数据的时间进行分类：

| 状态 | 圆点颜色 | 含义 |
| --- | --- | --- |
| **存活** | 绿色 | 采集器在预期的心跳窗口内已上报事件 |
| **失联** | 琥珀色 | 近期无事件，但仍在宽限期内，可能是短暂的网络问题或主机处于休眠 |
| **离线** | 红色 | 长时间无事件，可能是采集器已停止、主机已关机，或网络路径已中断 |
| **已停用** | 黑色 | 已手动停用，采集器已安装但预期不会上报 |

将鼠标悬停在表格中的任一状态圆点上，可查看完整图例。

## 主机表格

该表格列出与上方概要卡片中激活过滤器相匹配的每一台主机。

### 工具栏

| 控件 | 功能 |
| --- | --- |
| **搜索** | 按主机名、IP、实例 ID 或标签过滤。 |
| **固定排序** | 将当前通过拖放得到的行顺序保存为默认顺序。再次点击可恢复服务端排序。 |

### 列

| 列 | 说明 |
| --- | --- |
| **状态** | 彩色圆点：存活、失联、离线或已停用 |
| **主机** | 显示名称，当设置了 `env` 时还会附带一个环境标签胶囊（prod、staging、dev） |
| **类型** | 基础设施类型：VM、Kubernetes 节点等 |
| **最近上报** | 距上一批事件接收以来的相对时间 |
| **异常** | 该主机上待处理发现项的数量，若无则显示 "–" |
| **事件** | 已接收的事件总数 |
| **用户** | 该主机上观测到的不同身份 |
| **操作** | 行内菜单：重命名显示名称、停用/重新启用（在可用时） |

点击一行中的任意位置（拖动手柄或操作菜单除外），即可打开主机详情。

### 表格行为

- **排序** — 默认按最近上报时间排序（最新在前）。在支持的列标题上点击即可排序。
- **拖动重排** — 使用左侧的抓取手柄来重新排列各行。固定排序可保留你的排列方式。
- **分页** — 每页 50 台主机，配有上一页/下一页控件。
- **自动刷新** — 表格每 30 秒重新加载一次。
- **Kubernetes 分组** — 同一集群中的节点会折叠到单个可展开的集群行下。

## 主机详情

点击某一主机行即可打开。页面标题栏显示主机名称、状态和最近上报时间。一个 **采集器** 返回链接可让你回到主机群表格。

详情页包含四个部分：

### 身份

一张概括该主机当前状态的卡片：

- 状态徽章与基础设施类型
- 最近上报时间戳
- **标签**：来自采集器的键/值元数据（例如 `env`、`team`、云实例标签），在可用时附带来源和最后更新时间

标签来自采集器的云元数据或已配置的标签来源。

### 在线时长时间线

一条水平条带，展示采集器随时间变化的可用性。每个分段代表一个时间桶：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 在线 — 此时间桶内接收到了事件 |
| 琥珀色 | 离线 — 此时间桶内无活动 |
| 红色 | 已隔离 — 此期间主机处于被隔离状态 |

将鼠标悬停在某个分段上，可查看准确的时间戳和事件数。条带上方的概要行会显示总在线时长百分比和活跃小时数（例如 "已在线 6 天 14 小时 · 在线时长 98.2%"）。

### 指标

三张可点击的卡片，范围限定为当前主机和当前仪表盘时间窗口：

| 卡片 | 数值 | 跳转至 |
| --- | --- | --- |
| **事件数（24 小时）** | 事件计数 | 调查，按该主机过滤 |
| **活跃异常** | 待处理发现项计数 | 异常，按该主机过滤 |
| **活跃用户** | 不同身份 | 用户时间线，按该主机过滤 |

### 包含关系树

一棵可展开的树，展示该主机上正在运行的内容，数据派生自 cgroup 清单。

可在两种视图间切换：

| 视图 | 展示内容 |
| --- | --- |
| **Cgroups** | 完整的内核 cgroup 层级 — 主机 → 运行时 → pod → 容器。默认视图。 |
| **工作负载** | 按逻辑工作负载分组的扁平列表 — 每个 Kubernetes pod 或 Docker Compose 服务占一行。 |

每个节点都会显示事件数、字节传输量和血缘深度。展开节点可查看子进程和工作负载。可借此了解某主机上的哪些容器或服务产生了最多的活动。
