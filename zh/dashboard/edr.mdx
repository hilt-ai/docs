EDR 页面提供对运行 Hilt 采集器的 macOS 终端上安全相关活动的实时可见性。每个标签页聚焦于不同类别的终端行为，但它们共享相同的布局和控件。

---

## 通用布局

每个 EDR 标签页具有相同的结构：

- **Agent 标头**：显示当前主机 ID、风险等级、最后活跃时间、Endpoint Security 和 Network Extension 状态、策略版本以及发现项/事件计数的横栏。
- **摘要卡片**：每个活动组一张卡片，显示该组的计数和最高严重性。
- **时间线**：60 分钟的每分钟发现项面积图——峰值突出显示活动爆发。
- **严重性/状态过滤器**：按严重性（critical、high、medium、low、info）和 agent 响应（blocked、alerted、allowed、logged）过滤发现项。
- **发现项表格**：分组的、可折叠的发现项表格，包含时间、类型/目标、应用、严重性和状态列。重复的发现项折叠为带有计数徽章的可展开组。
- **发现项详情面板**：选择一个发现项后显示六部分分解：发生了什么、负责的进程、受影响的对象、为什么重要、证据和建议操作。

### 严重性级别

| 级别 | 含义 |
| --- | --- |
| **Critical** | 可能有害——优先调查 |
| **High** | 可疑，值得及时关注 |
| **Medium** | 值得注意但不太紧急 |
| **Low** | 轻微或信息性 |
| **Info** | 常规活动，记录备查 |

### Agent 响应状态

| 状态 | 含义 |
| --- | --- |
| **Blocked** | 操作已在设备上被主动阻止 |
| **Alerted** | 已标记以供审查 |
| **Allowed** | 操作被允许继续 |
| **Logged** | 已记录备查 |

## 持久化

**路由：** `/edr/persistence`

监控设置为自动启动并在重启后保持运行的程序——launch agent、launch daemon、登录项、cron 作业和后台任务管理（BTM）注册。

### 活动组

| 组 | 检测内容 |
| --- | --- |
| **Persistence items** | 新增或修改的 launch agent/daemon、计划任务和登录项 |

合法应用程序会常规使用持久化机制（例如更新程序、后台服务）。当未知或未签名的二进制文件注册为自动启动时，此处的发现项尤其值得关注。

---

## 防篡改检测

**路由：** `/edr/tamper`

检测削弱 macOS 安全控制或干扰 Hilt agent 本身的尝试。

### 活动组

| 组 | 检测内容 |
| --- | --- |
| **Gatekeeper** | 禁用或绕过 macOS Gatekeeper（阻止不受信任应用的保护机制）的尝试 |
| **MDM / Profiles** | 更改设备管理配置文件，可能改变安全设置 |
| **Agent tamper** | 停止、删除或禁用 Hilt 采集器的尝试——agent 会主动阻止这些操作 |

## 数据流动与外部传输

**路由：** `/edr/data-movement`

跟踪数据从终端流出的位置——外部上传、可移动介质写入和 AirDrop 传输。此标签页需要先选择特定终端才能显示数据。

### 活动组

| 组 | 检测内容 |
| --- | --- |
| **External uploads** | 文件被读取后发送到外部目的地 |
| **Removable media** | 文件写入 USB 驱动器或其他外部存储卷 |
| **AirDrop** | 通过 AirDrop 传输的文件 |

### 连接图

页面顶部的流程可视化显示终端的活跃网络连接——源进程、目的地和传输量。

### 发现项详情——流程图

数据流动发现项包含一个 **Flow** 部分，显示数据的传输路径：源文件、处理该文件的应用程序以及目标地址或设备。

## 凭据与隐私

**路由：** `/edr/credential`

监控对凭据存储和隐私敏感资源的访问。此标签页也需要先选择特定终端。

### 活动组

| 组 | 检测内容 |
| --- | --- |
| **Keychain** | 对 macOS Keychain（密码、密钥、证书）的访问 |
| **Browser credentials** | 对浏览器保存的密码和 cookie 的访问 |
| **TCC privacy database** | 对控制应用隐私权限（摄像头、麦克风、文件、屏幕）的数据库的访问 |
| **Camera / microphone** | 摄像头或麦克风何时被激活，以及由哪个应用程序激活 |

---

## 选择终端

数据流动和凭据标签页要求你在显示数据之前先选择一个终端。终端选择器列出所有上报 EDR 遥测数据的设备，包含主机名、主机 ID、总事件计数和最后活跃时间。你的选择会在跨页面访问时被记住。

你可以随时使用页面标头下方终端栏中的 **Change** 按钮来切换终端。
