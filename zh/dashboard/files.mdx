展示全主机群范围内文件正在发生的情况：打开、删除、权限变更和重命名，并让你以采集器所观测到的方式浏览某主机的文件系统。

---

## 主机群概览

### 搜索、选择与对比

- **搜索** 可按名称过滤主机。
- **行复选框**（表头带有全选）让你挑选要对比的主机。
- 当选中一台或多台主机时，**对比主机 (N)** 按钮会打开对比弹窗。

### 列

| 列 | 所计数的内容 |
| --- | --- |
| **主机** | 显示名称 |
| **打开** | 文件打开事件 |
| **删除** | unlink/删除事件 |
| **Chmod** | 权限变更 |
| **唯一路径** | 涉及的不同路径 |
| **敏感** | 在敏感路径上的活动 |

默认按"打开"排序，由高到低。与其他页面一样，主机会归入可展开的 Kubernetes 集群行，并且固定的主机排序（来自采集器页面）会禁用列排序。

## 单主机视图

选中某台主机会打开一个三段式工作区：左侧是 **文件浏览器**，中间是 **主面板**，底部沿边是一个可调整大小的 **迷你终端**。

### 搜索栏

主机视图顶部有一个搜索栏（占位符为 _Search by file name or path..._）。它会在你输入时进行防抖处理，并显示匹配的路径，附带文件类别徽章、路径归类和事件数。选中某条结果会导航到该文件的父目录并打开其详情弹窗。

### 文件浏览器

左侧边栏是一棵从 `/` 开始、按需懒展开的文件夹树：

- **文件夹行** 显示名称外加 `N paths · N evts`。
- **文件行** 显示基本名称和事件数。

它会遵循在浏览面板中设置的 **显示系统路径** 和 **显示隐藏项** 开关。

### 主面板

中间面板会根据你正在进行的操作显示以下三种状态之一：

#### 着陆

在你深入某个目录之前显示，是一份单主机概要：

| 部分 | 内容 |
| --- | --- |
| **统计卡片** | 总事件数 · 唯一路径 · 进程数 |
| **路径归类** | 按类别对路径分组的水平条 |
| **文件类别** | 类别 / 活动 / 不同文件 |
| **热门目录** | 目录、路径、事件 — 点击即可浏览 |
| **热门文件** | 路径、进程、事件 — 点击即可打开详情弹窗 |
| **值得关注的文件** | 路径、类别徽章、原因、首要进程，以及删除/chmod/重命名次数 |

#### 浏览

当你选中某个目录时：

- 一条 **当前位置** 面包屑，带有后退/前进箭头。
- 一个 **文件夹与文件** 标题，附带文件夹和文件路径的计数。
- **视图选项** 开关：**显示系统路径** 和 **显示隐藏项**（点文件）。
- 一张 **文件夹** 表格（Path · Paths inside · Events）和一张 **文件路径** 表格（Path · Class · Events · Procs · Del · Chmod · Top Process）。值得关注的文件会被高亮显示。

#### 文件列表

当搜索处于激活状态时，面板会显示 **文件路径**，每个不同路径占一行，使用与浏览文件表格相同的列。结果按总事件数排序，由高到低。

### 迷你终端

底部一个可调整大小的面板，与浏览器位置保持同步，并接受一小组命令：`cd`、`ls`、`tree`、`pwd`、`cat <file>` 和 `clear`。`cd ..` 会沿着浏览的后退栈回退。

## 文件详情

点击某个文件会打开详情弹窗。标题栏显示基本名称、完整路径，并在适用时显示一个 **已删除** 徽章。

| 部分 | 内容 |
| --- | --- |
| **身份** | 目录、扩展名、文件类别、路径归类、首次出现、最后出现 |
| **概览** | 打开、删除、Chmod、重命名；不同进程数和首要进程；一张按进程拆分的表格（Process · Opn · Del · Mod · Ren · Σ） |
| **谁动过它** | 进程、父进程、用户（身份、Teleport、SSH、所有者）、EUID、事件数和事件类型（打开、删除、权限、重命名） |
| **重命名与权限变更** | 类型、时间、路径、进程、EUID 和详情（旧→新路径或八进制权限模式） |
| **文件活动时间线** | 一张随时间变化的文件打开堆叠条形图 |

### 文件打开时间线

时间线图以打开次数（Y 轴）对各时间桶（X 轴）绘制出打开活动，并拆分为 **读取** 和 **写入** 两个序列。徽章汇总了总打开次数、活动是偏读还是偏写，以及峰值时间桶；**在调查中查看匹配事件** 会将该范围带到调查页面。

## 主机对比

**对比主机** 弹窗（从主机群概览打开）将所选主机横向排列在三个标签页中：

| 标签页 | 内容 |
| --- | --- |
| **活动概览** | 一张单主机指标表格（打开、删除、Chmod、唯一路径、敏感），外加一份按主机划分的文件类型分布 |
| **共享文件** | 在多于一台主机上出现过的路径 — Path · Hosts · Total Events · Accessed By，可排序 |
| **目录** | 热门目录的跨主机热力图 |
