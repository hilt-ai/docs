行为发现项的分流队列。每个发现项代表异常评分系统检测到的一次偏离（或由某条检测规则触发）；在此页面，你可以审阅它们，并将每一项标记为真实异常或误报。

---

## 过滤器

过滤通过 **Filters** 弹出框进行结构化设置：

| 区块 | 选项 |
| --- | --- |
| **Type** | All · Activity spike · Network · Sensitive file · Lateral movement · Detection rule |
| **Severity** | All · Critical · High · Medium · Low |
| **Source** | All · Detection rules · ML anomalies |
| **Sort by** | Time · Severity · Confidence · Urgency |
| **Visibility** | 一个 **Suppressed** 开关，用于显示因先前反馈而被隐藏的发现项 |

生效中的过滤器会以可移除的标签（chip）形式出现在标头下方。当你从某条检测规则范围进入时，会显示一个 **Rule:** {name} 标签，表明当前生效的范围。

## 发现项队列

队列按审阅状态拆分为三个标签页：

| 标签页 | 内容 |
| --- | --- |
| **Review** | 等待裁决的发现项 |
| **Accepted** | 你已确认为真实的发现项 |
| **Denied** | 你已驳回的发现项 |

### 发现项卡片

每个发现项都是一张卡片，展示：

- **标题（Headline）**：该发现项的叙述标题（或其行为标签）。
- **相对时间** 与简短的 **主机名**。
- **类型**：例如 _Type: Activity spike_（已分类时）。
- **裁决**：审阅后显示 **Accepted** 或 **Denied** 徽章。
- 一行说明发生了什么的 **摘要**，并内嵌事件标签（chip）。
- 当行为对该主机而言不典型时，显示 **cluster** 徽章。
- **User / Reviewer** 和 **Confidence**（High / Medium / Low）。
- 当主机已被隔离时，显示 **Host quarantined · View** 链接。

被选中的卡片以绿色强调色高亮。严重程度可用作过滤条件，但不会打印在卡片上。

## 发现项详情

选择某个发现项会在右侧面板中打开它的报告。（如果未选择任何项，面板会提示你 _“Select a finding from the queue to view details.”_）报告分为两部分。

### 叙述

顶部条带解释该发现项：

- **标题（Headline）**，附带 **主机** 和发现项的 **时间**。
- 一个 **type** 徽章和一个 **confidence** 徽章（悬停可见 “Model Confidence”）。
- 适用时显示 **Quarantined** 链接。
- 叙述本身，即 _发生了什么_，以及一个 **Why unusual** 区块，外加上下文标签（chip）。
- 涉及的作业、应用或工作负载的 **Identity** 徽章。

可能会出现两条上下文横幅：一条 **workload phase change** 提示（说明仅基于流量的信号已被弱化处理），以及当该模式与某位审阅者先前驳回过的发现项相匹配时的 **feedback-suppression** 提示，其中包含模式相似度（精确匹配或一个百分比）。

### 审阅发现项（Confirm / Dismiss）

在叙述条带中，你对该发现项采取行动：

- **Confirm**：将其标记为真实异常（移至 **Accepted**）。
- **Dismiss**：将其标记为良性或误报（移至 **Denied**）。
- 一个备注字段（_“Add review notes...”_）可让你记录上下文。

### 事件时间线

在叙述下方，一条 **泳道时间线（swimlane timeline）** 将证据绘制在一个五分钟窗口内的三条泳道中：**Process**、**Network** 和 **File**。节点按其贡献强度着色（图例涵盖 _key contributor_、_involved_、_background_ 和 _strongest link_），点击某个节点会固定一个工具提示，显示 PID、父进程、时间、相关性评分与排名，以及其关联事件。连接弧线标注为 _strong_、_moderate_ 或 _weak link_。
