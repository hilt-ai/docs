## 过滤器

过滤器在标头处按标签页分组：**Event**、**Process**、**Network**、**File**、**Topology** 和 **Location**。每个标签页都会打开一个结构化字段面板：

| 标签页 | 你可过滤的内容 |
| --- | --- |
| **Event** | 事件类型，分为 Process、Files、Network 和 Workloads（例如 _Process started_、_File opened_、_Network flow_） |
| **Process** | 命令、父命令、PID、线程 ID、父 PID、UID、有效 UID、用户、工作负载 ID |
| **Network** | 源/目标 IP 和端口、协议、连接类型、发送/接收字节数阈值 |
| **File** | 路径前缀、打开标志（open flags）、权限位、命令行包含项 |
| **Topology** | 程序 ID、会话 ID、进程实例 ID |
| **Location** | 主机（多选）、boot ID、容器 ID、Pod UID |

生效中的过滤器会显示为可移除的标签（chip），并提供 **Clear all** 进行重置。过滤完全是结构化的。

## 时间线滑块

在事件列表上方，一个 **Activity** 直方图绘制了事件量随时间的变化 —— 每个时间桶一根柱子，计数在 Y 轴上。

- **拖拽以缩放** —— 选择一个区域以收窄窗口；该选区会成为一个自定义范围。
- **Back** 和 **Reset** 逐级退出缩放层级。
- **异常叠加层** —— 琥珀色条带标记发现项出现的窗口（±2.5 分钟）。
- 悬停某个桶会显示其事件计数和时间。

---

### 展开事件

点击某一行将其展开。如果该事件与某个发现项重叠，会有一条 **Anomaly overlap** 横幅解释原因。展开后会显示特定类型的取证字段、路径、命令行、流、用户、血缘、UID，以及诸如 **Connections to…**、**File access for…** 和 **Data Lineage** 等跳转链接，外加一个用于显示完整取证详情（身份、执行、运行时等）的 **More / Less** 切换。

### 加载更多

事件每次加载 200 条。使用 **Show more** 获取更早的事件。

## 事件列表

滑块下方是事件列表。尽管内部称为“进程组（process group）”列表，但它是一个 **扁平的、按时间顺序排列的列表 —— 每个事件一行**，并不会归到进程标头之下分组。

### 工具栏

- **Sort** —— 按 **Newest** 或 **Oldest** 在前。
- 一个 {n} **loaded** 计数。
- **Refresh** —— 手动重新加载（列表不会自动轮询；异常标记每 30 秒会刷新一次）。

标头标题为 **Investigate**，副标题反映你是如何到达这里的 —— 例如 _“All hosts · 12,340 events”_、_“web-01 · 512 events”_，或者当从某个发现项进入时，显示 _“Investigating: \<alert group\> - \<host\>”_，标明该发现项的分组和主机。

- **Sort** —— 按 **Newest** 或 **Oldest** 在前。
- 一个表示已加载事件数的计数。
- **Refresh** —— 手动重新加载（列表不会自动轮询；异常标记每 30 秒会刷新一次）。
