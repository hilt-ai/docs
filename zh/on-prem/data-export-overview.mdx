## 目的

Hilt 的检测模型在使用多样化的真实行为模式进行训练时会得到改进。对于选择加入的客户，结构化导出管道会生成匿名化的统计摘要，帮助在不同基础设施类型间校准检测阈值。

---

## 导出内容

| 数据类别 | 描述 | 安全原因 |
| :-- | :-- | :-- |
| **聚合数值特征** | 每 5 分钟 epoch 的计数（如执行次数、传输字节数、唯一目的地数） | 无原始值——仅聚合统计 |
| **派生统计特征** | 聚合计数的比率、熵和数学变换 | 对聚合值的纯数学运算 |
| **抽象活动令牌** | 封闭词汇表的活动类型序列（不含文件名、IP 或命令） | 所有身份信息在令牌化时已被移除 |
| **异常标签** | 二元异常标记和评分阶段标签 | 无客户特定上下文 |
| **时间键** | 5 分钟时段时间戳（抖动 ±0–48 小时） | 防止日历关联 |

---

## 绝不导出的内容

| 数据 | 原因 |
| :-- | :-- |
| 文件路径、命令行、参数 | 直接泄露基础设施/个人信息 |
| IP 地址、主机名、DNS 名称 | 网络拓扑暴露 |
| 用户名、SSH 身份、Okta 数据 | 身份泄露 |
| 云资源 ID（实例、IAM 角色、区域） | 账户指纹化 |
| 容器/Pod 名称和命名空间 | Kubernetes 拓扑 |
| 检测规则名称和匹配逻辑 | 客户安全态势 |
| 自由文本告警解释 | 可能回显敏感事件上下文 |
| 仪表盘账户和会话 | 访问凭据暴露 |

---

## 匿名化

导出前，所有身份信息都会被剥离或重新映射：

- **Host ID** → 确定性顺序重映射（`host-0001`、`host-0002`、…）
- **User ID** → 每主机的顺序整数
- **所有者/身份字符串** → 完全丢弃
- **时间戳** → 随机偏移 0–48 小时以防止日历关联
- **最低主机阈值** → 少于 5 台主机的导出将被拒绝

---

## 客户控制

### 传输前审核

当需要审批时（默认设置），导出会生成一个清单和小型样本文件。完整归档会暂存，但在您明确批准之前**不会传输**。您可以：

- 检查清单以验证具体包含哪些列
- 加载样本文件以确认匿名化效果
- 从存储桶中删除暂存文件以拒绝导出

### 日期范围控制

您可控制导出的历史数据量，并可限定特定时间窗口。

### 删除

您可随时从存储桶中删除已导出的数据。

### 审计追踪

每次导出都会创建一条日志事件，包含导出 ID、行数、日期范围和审批状态。Host ID 映射文件仅保留在您的存储桶中。

---

## Hilt 收到的内容

仅行为特征向量和抽象活动序列。不含文件名、IP 地址、主机名、用户名、云资源 ID、检测规则名称或匹配描述。
