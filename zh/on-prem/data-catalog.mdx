本页描述 Hilt 平台关于您环境所存储的数据类别。内容按各数据类别的含义组织，而非按内部存储细节。

---

## 事件遥测

平台从您的主机收集的主要数据。每条记录代表一个已观测到的系统事件。

| 类别 | 包含内容 |
| :-- | :-- |
| **进程执行** | 命令名称、父进程、PID、用户 ID、时间戳、命令行参数 |
| **文件操作** | 被访问的文件路径、操作类型（打开、重命名、删除、权限变更）、用户和进程上下文 |
| **网络流** | 源/目标 IP 和端口、协议、发送/接收字节数、连接范围（内部/外部） |
| **主机标识** | Host ID、主机名、云区域、实例 ID、集群归属 |
| **用户标识** | 操作系统用户名、解析后的所有者身份、SSH 身份、身份来源及置信度 |
| **容器/Kubernetes 上下文** | 容器 ID、Pod 名称/命名空间、工作负载控制器、cgroup 信息 |
| **工作负载与应用标识** | 逻辑工作负载分组、应用名称、应用类型 |

---

## 异常检测

检测与评分管道产生的数据。

| 类别 | 包含内容 |
| :-- | :-- |
| **异常评分** | 各检测通道每个 epoch 的数值评分、异常标记、评分阶段 |
| **告警叙述** | AI 生成的发现解释：发生了什么、为何异常、涉及哪些身份 |
| **行为聚类** | 全舰队行为分组及标签、主机归属、迁移历史 |
| **检测规则匹配** | 规则名称、严重性、匹配条件、受影响主机及时间窗口 |

---

## 人工审核

您团队的分诊活动所产生的数据。

| 类别 | 包含内容 |
| :-- | :-- |
| **审核判定** | 发现 ID、判定结果（确认/驳回）、审核人员、置信度、备注 |
| **反馈事件** | 判定结果反馈至检测模型以抑制已知正常模式 |

---

## 仪表盘与访问

Web 仪表盘所使用的数据。

| 类别 | 包含内容 |
| :-- | :-- |
| **用户账户** | 仪表盘登录凭据（已哈希）、角色、团队归属 |
| **团队** | 团队层级、各团队的主机分配 |
| **会话** | 活跃登录会话 |
| **审计日志** | 仪表盘用户执行的管理操作 |
| **主机记录** | 显示名称、隔离状态、标签、网络前缀清单 |
| **身份目录** | 缓存的 Okta/IdP 目录，用于身份解析 |

---

## 每小时汇总

用于仪表盘性能的预聚合计数器。包含每主机、每小时的事件计数，不含原始事件详情。

---

## 数据保留

保留策略可按部署进行配置。请联系您的客户团队了解当前设置和可用选项。

---

## Hilt 无法看到的内容

采集器不捕获文件内容、数据包载荷、环境变量、内存内容或击键记录。平台存储的是关于系统活动的元数据，绝非数据本身。
