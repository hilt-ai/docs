Hilt's macOS endpoint coverage extends data detection and response to macOS endpoints using the Apple Endpoint Security framework and a managed Chrome extension, complementing the Linux collector that covers your server infrastructure.

This page will cover provisioning macOS endpoints, including MDM-based deployment of the system extension and the Chrome extension. For current capabilities, see the [macOS Collector](/macos-collector/layout) page.
